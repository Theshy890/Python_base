## 知识点 8.1：迭代器——逐个取出数据

### ① 一句话通俗定义
**迭代器 = 一个可以逐个取出元素的容器。**

就像自动售货机：你每次按按钮，它吐出一个商品，而不是一次性把所有商品都倒出来。

### ② 生活例子类比

| 列表（一次性全部拿出） | 迭代器（逐个取出） |
|----------------------|-------------------|
| 把一整箱苹果搬回家 | 每次从箱子里拿一个苹果 |
| 内存占用大 | 内存占用小 |
| 适合数据量小 | 适合大数据处理 |

### ③ 语法说明

```python
# 创建迭代器
nums = [1, 2, 3, 4, 5]
iterator = iter(nums)  # 把列表变成迭代器

# 逐个取出（用next()）
print(next(iterator))  # 1
print(next(iterator))  # 2
print(next(iterator))  # 3

# 用for循环遍历（自动调用next()）
for num in iterator:
    print(num)  # 4, 5

# 手动实现迭代器类
class NumberGenerator:
    def __init__(self, max_num):
        self.max_num = max_num
        self.current = 0

    def __iter__(self):
        # 返回迭代器对象本身
        return self

    def __next__(self):
        # 返回下一个元素
        if self.current < self.max_num:
            self.current += 1
            return self.current
        else:
            # 没有元素了，抛出StopIteration
            raise StopIteration

# 使用自定义迭代器
gen = NumberGenerator(3)
for num in gen:
    print(num)  # 1, 2, 3
```

### ④ AI开发场景
- 分批处理大型数据集（每次处理100条，避免内存溢出）
- 流式读取大文件（边读边处理）

## 知识点 8.2：生成器——按需生成数据

### ① 一句话通俗定义
**生成器 = 用函数语法写的迭代器，用yield关键字返回数据。**

就像一个魔法工厂：你要一个产品，它生产一个；你再要一个，它再生产一个，而不是一次性生产完所有产品。

### ② 语法说明

```python
# 生成器函数（用yield代替return）
def generate_numbers(max_num):
    current = 1
    while current <= max_num:
        yield current  # 暂停执行，返回当前值
        current += 1   # 下次调用时从这里继续

# 使用生成器
gen = generate_numbers(3)
print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # 3

# 用for循环遍历
for num in generate_numbers(5):
    print(num)  # 1, 2, 3, 4, 5

# 生成器表达式（类似列表推导式，但用()）
squares = (x**2 for x in range(1, 6))
for square in squares:
    print(square)  # 1, 4, 9, 16, 25
```

### ③ yield的魔法

| 普通函数 | 生成器函数 |
|---------|-----------|
| 用return返回，执行完就结束 | 用yield返回，暂停执行，下次继续 |
| 一次性返回所有结果 | 按需返回，节省内存 |
| 调用时立即执行 | 调用时返回生成器对象，不立即执行 |

### ④ AI开发场景

```python
# 分批处理大数据集
def batch_process(data, batch_size=100):
    for i in range(0, len(data), batch_size):
        yield data[i:i+batch_size]

# 假设有1000条数据需要处理
all_data = list(range(1000))

# 每次处理100条
for batch in batch_process(all_data, 100):
    print(f"处理批次，数量：{len(batch)}")
    # 调用AI模型处理这个批次
```

## 知识点 8.3：装饰器——给函数"穿衣服"

### ① 一句话通俗定义
**装饰器 = 一个包装函数的函数，可以在不修改原函数代码的情况下，给它添加额外功能。**

就像给手机贴钢化膜、装手机壳：手机本身的功能没变，但多了保护功能。

### ② 语法说明

```python
# 定义装饰器
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)  # 调用原函数
        end = time.time()
        print(f"函数 {func.__name__} 执行时间：{end-start:.2f}秒")
        return result
    return wrapper

# 使用装饰器（@语法）
@timer
def slow_function():
    import time
    time.sleep(1)
    print("函数执行完成")

slow_function()
# 输出：
# 函数执行完成
# 函数 slow_function 执行时间：1.00秒

# 多个装饰器叠加
def logger(func):
    def wrapper(*args, **kwargs):
        print(f"调用函数：{func.__name__}，参数：{args}")
        result = func(*args, **kwargs)
        print(f"函数返回：{result}")
        return result
    return wrapper

@logger
@timer
def add(a, b):
    return a + b

add(3, 5)
# 输出：
# 调用函数：wrapper，参数：(3, 5)
# 函数 add 执行时间：0.00秒
# 函数返回：8
```

### ③ functools.wraps——保留原函数信息

```python
import functools

def timer(func):
    @functools.wraps(func)  # 保留原函数的__name__等信息
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"执行时间：{end-start:.2f}秒")
        return result
    return wrapper

@timer
def my_function():
    pass

print(my_function.__name__)  # my_function（如果没有@functools.wraps会显示wrapper）
```

## 知识点 8.4：带参数的装饰器

### ① 一句话通俗定义
**带参数的装饰器 = 装饰器本身也可以接受参数。**

就像手机壳可以选不同颜色：装饰器的功能可以根据参数调整。

### ② 语法说明

```python
def repeat(times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            results = []
            for _ in range(times):
                results.append(func(*args, **kwargs))
            return results
        return wrapper
    return decorator

@repeat(times=3)
def say_hello():
    return "Hello!"

result = say_hello()
print(result)  # ['Hello!', 'Hello!', 'Hello!']

# AI开发场景：添加重试机制
def retry(max_attempts=3):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_attempts - 1:
                        raise e
                    print(f"第{attempt+1}次失败，重试中...")
        return wrapper
    return decorator

@retry(max_attempts=3)
def call_api():
    import random
    if random.random() > 0.3:
        raise Exception("API调用失败")
    return "成功"

print(call_api())
```

## 知识点 8.5：高阶函数——函数作为参数和返回值

### ① 一句话通俗定义
**高阶函数 = 可以接受函数作为参数，或者返回一个函数的函数。**

就像一个工厂：你给它一个零件（函数），它用这个零件组装出一个新产品（新函数）。

### ② 常用高阶函数

```python
# map：对每个元素应用函数
numbers = [1, 2, 3, 4]
squares = list(map(lambda x: x**2, numbers))
print(squares)  # [1, 4, 9, 16]

# filter：过滤符合条件的元素
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]

# sorted：排序，接受key函数
words = ["apple", "banana", "cherry", "date"]
sorted_by_length = sorted(words, key=lambda x: len(x))
print(sorted_by_length)  # ['date', 'apple', 'banana', 'cherry']
```

## 知识点 8.6：AI开发实战——装饰器的应用

### 场景1：添加重试机制

```python
import time
import functools

def retry_on_failure(max_retries=3, delay=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries - 1:
                        raise e
                    print(f"调用失败（{e}），{delay}秒后重试...")
                    time.sleep(delay)
        return wrapper
    return decorator

@retry_on_failure(max_retries=3, delay=2)
def call_ai_api(prompt):
    # 模拟AI API调用，可能失败
    import random
    if random.random() > 0.5:
        raise Exception("网络超时")
    return f"AI回复：{prompt}"

print(call_ai_api("你好"))
```

### 场景2：添加缓存

```python
def memoize(func):
    cache = {}
    @functools.wraps(func)
    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]
    return wrapper

@memoize
def expensive_computation(n):
    # 模拟耗时计算
    import time
    time.sleep(1)
    return n * n

print(expensive_computation(5))  # 耗时1秒
print(expensive_computation(5))  # 立即返回（从缓存）
print(expensive_computation(10)) # 耗时1秒
```

### 场景3：添加日志记录

```python
def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        import datetime
        timestamp = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        print(f"[{timestamp}] 调用 {func.__name__}({args}, {kwargs})")
        result = func(*args, **kwargs)
        print(f"[{timestamp}] {func.__name__} 返回：{result}")
        return result
    return wrapper

@log_calls
def process_text(text):
    return text.upper()

process_text("hello world")
# 输出：
# [2024-07-15 10:30:00] 调用 process_text(('hello world',), {})
# [2024-07-15 10:30:00] process_text 返回：HELLO WORLD
```
