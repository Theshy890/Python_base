#### 学习理论

**目标**：深入理解知识点，掌握理论体系

**方法**：
1. 打开对应阶段的`理论.md`文件
2. 逐节阅读，理解每个知识点
3. 重点关注"AI开发用途"部分
4. 配合`知识点思维导图.md`梳理知识结构
5. 在`补充知识点速记.md`中标记重点


#### 完成练习题

**目标**：检验学习效果，提升实战能力

**方法**：
1. 打开对应阶段的`阶段X综合测试题.md`文件
2. **先思考再看答案**：不要直接抄答案
3. 做完后对照答案，分析错误原因
4. 把错题记录到`新增易错点对照表.md`
5. 尝试用不同方法解决同一问题



#### 复习巩固

**目标**：巩固所学知识，形成长期记忆

**方法**：
1. 回顾`补充知识点速记.md`中的要点
2. 对照`知识点思维导图.md`检查知识漏洞
3. 更新`学习进度记录.md`标记阶段完成
4. 总结本阶段学到的AI开发技能

## 四、各阶段学习重点

### 阶段1：Python初相识
- **重点**：变量、数据类型、运算符、字符串操作
- **AI用途**：构造提示词、处理API响应
- **关键技能**：写出第一个程序

### 阶段2：条件判断与循环
- **重点**：if判断、for/while循环、逻辑运算
- **AI用途**：判断用户意图、批量处理数据
- **关键技能**：让代码会"思考"

### 阶段3：数据容器
- **重点**：列表、字典、元组、集合、可变/不可变对象
- **AI用途**：存储对话历史、解析JSON数据
- **关键技能**：熟练使用数据容器

### 阶段4：函数与模块
- **重点**：函数定义、参数传递、模块导入、json模块
- **AI用途**：封装API调用、解析模型响应
- **关键技能**：代码复用和模块化

### 阶段5：文件操作与异常处理
- **重点**：文件读写、异常处理、os模块、编码规范
- **AI用途**：构建本地RAG知识库、保存对话记录
- **关键技能**：处理文件和异常

### 阶段6：正则表达式
- **重点**：re模块、正则语法、文本清洗、信息提取
- **AI用途**：清洗用户输入、提取关键信息、过滤内容
- **关键技能**：高效处理文本数据

### 阶段7：面向对象编程
- **重点**：类定义、继承、多态、私有属性、property
- **AI用途**：封装AI模型、统一接口设计
- **关键技能**：面向对象设计

### 阶段8：迭代器生成器与装饰器
- **重点**：迭代器、生成器yield、装饰器@、高阶函数
- **AI用途**：大数据处理、性能优化、API重试
- **关键技能**：编写高效代码

### 阶段9：多线程多进程并发
- **重点**：threading、multiprocessing、线程池、asyncio
- **AI用途**：并发调用API、批量任务处理
- **关键技能**：并发编程

## 六、学习工具使用指南

### VS Code使用建议
1. **安装Python扩展**：提供语法高亮、代码提示
2. **配置Python解释器**：选择Anaconda环境
3. **使用终端运行代码**：点击"运行"按钮或按F5
4. **使用调试功能**：设置断点，逐步执行代码

### Jupyter Notebook使用建议
1. **用于交互式学习**：适合测试代码片段
2. **用于记录学习笔记**：可以混合文字和代码
3. **用于演示代码效果**：直观展示运行结果

### 终端使用建议
1. **退出Python交互模式**：输入`exit()`或按Ctrl+Z
2. **运行Python文件**：`python 文件名.py`
3. **安装第三方库**：`pip install 库名`

## 七、常见问题解答

### Q1：学习进度怎么追踪？
**A**：使用`基础/总复习笔记/学习进度记录.md`，完成一个阶段后更新状态。

### Q2：遇到报错怎么办？
**A**：
1. 看报错信息的最后一行（错误类型）
2. 看报错信息的行号（哪里出错）
3. 对照`新增易错点对照表.md`查找解决方案
4. 使用AI辅助学习提示词让AI分析错误

### Q3：练习题不会做怎么办？
**A**：
1. 先回顾理论.md中相关知识点
2. 看答案前先尝试思考解决思路
3. 理解答案后，尝试用自己的方法重写

### Q4：理论和视频内容不一致怎么办？
**A**：以理论.md为准，视频是实操补充。理论.md整合了三套资料的内容。

### Q5：需要安装哪些软件？
**A**：
- VS Code（代码编辑器）
- Anaconda（Python环境）
- Python 3.10（推荐版本）

## 八、学习心态建议

### 保持耐心
- 编程学习需要时间，不要急于求成
- 遇到难点是正常的，多花时间理解

### 多动手实践
- 编程是技能，需要大量练习
- 每个demo都要亲手敲一遍，不要复制粘贴

### 积极解决问题
- 遇到报错不要慌，仔细看错误信息
- 尝试自己解决问题，培养独立思考能力

### 定期总结
- 每周总结一次学习成果
- 记录学到的新知识和技能
