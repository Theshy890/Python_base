## 知识点 5.1：文件读写

### ① 一句话通俗定义
**文件读写 = 程序把数据存到硬盘上（写），或从硬盘上读取数据（读）。**

### ② 生活例子类比
文件读写就像**记账本**：
- 写文件 = 把今天的开销记到本子上（数据持久保存）
- 读文件 = 翻开本子看昨天记了什么（读取历史数据）

AI应用开发中，把AI处理结果保存到txt/csv文件、读取配置文件、导出处理报告，全靠文件操作。

### ③ 语法说明

> 📌 **专业术语解释**：
> - **with语句**：Python的"上下文管理器"，自动帮你打开和关闭文件，不用担心忘记关文件导致资源浪费
> - **open()函数**：打开文件的内置函数，返回一个"文件对象"（就像打开书后拿到的书本身）
> - **文件对象**：用`as f`给文件对象起个名字叫`f`，后面用`f.write()`或`f.read()`来操作
> - **encoding="utf-8"**：指定文件编码为UTF-8，确保中文正常显示（必须写，不然中文会乱码）

```python
# 写文件（会覆盖原内容）
# with open(文件名, 模式, 编码) as 文件对象名:
# "w" = write模式，会清空原文件内容再写入（覆盖写）
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("第一行内容\n")  # f.write() = 写入字符串，\n是换行符
    f.write("第二行内容\n")

# 追加写（不覆盖，在末尾添加）
# "a" = append模式，在文件末尾追加内容，不会清空原内容
with open("output.txt", "a", encoding="utf-8") as f:
    f.write("追加的内容\n")

# 读文件（读取全部内容）
# "r" = read模式，只读文件，不能写
with open("output.txt", "r", encoding="utf-8") as f:
    content = f.read()  # f.read() = 一次性读取整个文件的全部内容
    print(content)

# 按行读取（推荐，省内存）
with open("output.txt", "r", encoding="utf-8") as f:
    for line in f:  # 直接遍历文件对象，每次循环得到一行
        print(line.strip())  # strip() = 去掉字符串两端的空格和换行符

# 读取所有行到列表（一次性加载到内存）
with open("output.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()  # f.readlines() = 返回一个列表，每个元素是一行
    print(lines)  # ['第一行内容\n', '第二行内容\n', ...]
```

**文件打开模式**：
| 模式 | 中文解释 | 文件不存在时 |
|------|---------|-------------|
| `"r"` | 读取（read） | 报错（找不到文件） |
| `"w"` | 写入（write），**会覆盖原内容** | 自动创建新文件 |
| `"a"` | 追加（append），**在末尾添加** | 自动创建新文件 |

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `FileNotFoundError` | 读取的文件不存在 | 检查文件路径，或先用`os.path.exists()`判断 |
| 中文显示乱码 | 没指定编码`encoding="utf-8"` | 打开文件时加`encoding="utf-8"` |
| 写文件后内容为空 | 用了`"w"`模式覆盖了原文件 | 要追加用`"a"`模式 |
| 忘记关闭文件 | 没用`with`语句 | 用`with open() as f:`自动关闭 |

### ⑤ 精简背诵笔记

```
【文件读写】
✓ with open("文件", "模式", encoding="utf-8") as f:
✓ 模式：r读取、w写入(覆盖)、a追加
✓ 写：f.write("内容")
✓ 读全部：f.read()
✓ 按行读：for line in f: 或 f.readlines()
✓ 必须指定encoding="utf-8"处理中文
✓ with语句会自动关闭文件
```

## 知识点 5.2：异常处理

### ① 一句话通俗定义
**异常处理 = 给程序装"安全气囊"，遇到错误时不崩溃，而是优雅处理。**

### ② 生活例子类比
异常处理就像**开车时的安全气囊**：
- 正常情况：车正常开（代码正常执行）
- 出车祸了：气囊弹出来保护你（捕获异常，程序不崩溃）
- 你可以选择：修车继续开（处理异常后继续）或叫拖车（记录错误并退出）

AI应用开发中，网络请求可能失败、文件可能不存在、AI接口可能超时——没有异常处理，程序一遇到这些问题就崩溃。

### ③ 语法说明

> 📌 **专业术语解释**：
> - **异常（Exception）**：程序运行时发生的错误，比如除以0、文件不存在、类型不对等
> - **try块**：放"可能出错的代码"，Python会尝试执行这里的代码
> - **except块**：如果try块里出错了，就执行except块里的"补救措施"
> - **ZeroDivisionError**：除以0时抛出的异常类型（除数为零错误）
> - **ValueError**：值错误，比如把"abc"转成整数时就会报这个错
> - **TypeError**：类型错误，比如用数字加字符串就会报这个错
> - **FileNotFoundError**：文件不存在错误
> - **Exception**：所有异常的"老大"，捕获Exception就能捕获所有异常
> - **as e**：把错误信息存到变量`e`里，可以打印出来看看具体错在哪
> - **finally**：无论有没有出错都会执行，常用于清理工作（比如关文件）
> - **raise**：主动抛出异常，告诉调用者"这里出错了！"

```python
# 基本try-except（最常用）
try:
    # try块：放可能出错的代码
    result = 10 / 0  # 这里会出错！除以0
    print(result)    # 因为上面出错了，这行不会执行
except ZeroDivisionError:  # 捕获"除数为零"这个特定异常
    # except块：出错后执行的补救措施
    print("错误：除数不能为0！")

# 捕获多种异常（针对不同错误做不同处理）
try:
    num = int("abc")  # 这里会出错！"abc"不是数字
except ValueError:  # 值错误：字符串不能转成整数
    print("错误：不是有效的数字！")
except TypeError:   # 类型错误：参数类型不对（比如传了列表）
    print("错误：类型不对！")

# 捕获所有异常（不推荐，但有时有用）
# Exception是所有异常的父类，抓它就等于抓所有异常
try:
    result = 10 / 0
except Exception as e:  # as e：把错误信息存到变量e里
    print("出错了：" + str(e))  # 打印具体错误信息

# finally：无论是否出错都会执行（常用于清理）
try:
    f = open("test.txt", "r")  # 可能找不到文件
    content = f.read()
except FileNotFoundError:  # 捕获文件不存在错误
    print("文件不存在！")
finally:  # 不管有没有出错，都会执行这里
    print("清理工作完成")

# 主动抛出异常（告诉调用者哪里错了）
def divide(a, b):
    if b == 0:
        # raise：主动抛出异常，像喊"这里出错了！"
        raise ValueError("除数不能为0")
    return a / b

try:
    divide(10, 0)  # 调用函数，会触发raise
except ValueError as e:  # 捕获主动抛出的异常
    print("错误：" + str(e))
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| 用了`except:`捕获所有异常 | 太宽泛，会掩盖真正的bug | 指定具体异常类型 |
| try块里代码太多 | 出错时不知道是哪行出的问题 | try块尽量小，只包可能出错的代码 |
| 忘记处理异常 | 程序遇到错误直接崩溃 | 关键操作都要加try-except |
| except里什么都不做 | 错误被吞掉了，很难调试 | except里至少要print或记录错误 |

### ⑤ 精简背诵笔记

```
【异常处理】
✓ try: 可能出错的代码
✓ except 异常类型: 出错后的处理
✓ except Exception as e: 捕获所有异常，e是错误信息
✓ finally: 无论是否出错都执行（常用于清理）
✓ raise: 主动抛出异常
✓ 常见异常：ValueError、TypeError、FileNotFoundError、ZeroDivisionError
```

## 知识点 5.3：综合实战

### ① 一句话通俗定义
**把前面学的所有知识串起来，做一个完整的小项目。**

### ② 实战项目：AI文本处理工具

> 📌 **专业术语解释**：
> - **函数文档字符串**：用`"""注释内容"""`写在函数开头，说明函数的作用（鼠标悬停在函数名上能看到）
> - **timestamp（时间戳）**：记录当前时间的字符串，格式如"2024-01-01 12:00:00"
> - **日志（log）**：记录程序运行过程的文件，方便排查问题

```python
# 导入需要的模块
import json      # 处理JSON数据
import os        # 处理文件路径
from datetime import datetime  # 获取当前时间

# 定义函数：清洗文本
def clean_text(text):
    """清洗文本：去空格、转小写"""
    # strip() = 去掉两端空格和换行符
    # lower() = 转成小写字母
    return text.strip().lower()

# 定义函数：处理文件（读取→清洗→保存）
def process_file(input_file, output_file):
    """处理文件：读取→清洗→保存"""
    try:
        # ① 读取输入文件（用readlines()把所有行读到列表里）
        with open(input_file, "r", encoding="utf-8") as f:
            lines = f.readlines()

        # ② 处理每一行
        cleaned_lines = []  # 空列表，用来存处理后的行
        index = 0           # 行号计数器，从0开始
        for line in lines:
            index = index + 1  # 行号加1
            cleaned = clean_text(line)  # 调用清洗函数
            # 拼接成"第1行：内容"的格式，添加到列表
            cleaned_lines.append("第" + str(index) + "行：" + cleaned)
            # 打印处理过程，方便调试
            print("处理第" + str(index) + "行：'" + line.strip() + "' -> '" + cleaned + "'")

        # ③ 保存到输出文件（用"w"模式，覆盖写）
        with open(output_file, "w", encoding="utf-8") as f:
            for line in cleaned_lines:
                f.write(line + "\n")  # 写入一行，加换行符

        print("\n处理完成！结果已保存到：" + output_file)
        return True  # 返回True表示成功

    except FileNotFoundError:  # 捕获文件不存在错误
        print("错误：文件 '" + input_file + "' 不存在！")
        return False  # 返回False表示失败
    except Exception as e:  # 捕获其他所有错误
        print("处理出错：" + str(e))
        return False

# 定义函数：保存日志
def save_log(log_file, message):
    """保存日志（带时间戳）"""
    # datetime.now() = 获取当前时间
    # strftime() = 格式化时间为字符串，格式是"年-月-日 时:分:秒"
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    # 用"a"模式追加写入日志
    with open(log_file, "a", encoding="utf-8") as f:
        f.write("[" + timestamp + "] " + message + "\n")

# --- 主程序开始 ---
# ① 创建测试文件（准备要处理的原始数据）
with open("input.txt", "w", encoding="utf-8") as f:
    f.write("  Hello World  \n")
    f.write("  PYTHON IS GREAT  \n")
    f.write("  AI Development  \n")

# ② 调用处理函数，处理input.txt并保存到output.txt
success = process_file("input.txt", "output.txt")

# ③ 根据处理结果记录日志
if success:
    save_log("process.log", "文件处理成功")
else:
    save_log("process.log", "文件处理失败")
```

```

✓ 函数封装：每个功能独立成函数
✓ 异常处理：文件操作必须加try-except
✓ 日志记录：关键操作记录时间和结果
✓ 编码统一：全部用utf-8
```

## 【补充】知识点 5.4：绝对路径与相对路径

### ① 一句话通俗定义
**绝对路径 = 从磁盘根目录开始的完整地址；相对路径 = 从当前文件夹开始的位置。**

### ② 生活例子类比
- **绝对路径**：完整邮寄地址 → "北京市海淀区中关村大街1号"（无论你在哪，这个地址唯一确定）
- **相对路径**：相对位置描述 → "从当前位置往东走100米"（取决于你在哪）

AI应用开发中，读写文件时必须清楚路径，否则找不到文件或写错位置。

### ③ 语法说明

> 📌 **专业术语解释**：
> - **绝对路径**：从磁盘根目录开始的完整地址，比如`C:\Users\Admin\data.txt`，无论在哪都能找到
> - **相对路径**：相对于当前程序运行位置的路径，比如`data/input.txt`，要看当前在哪个文件夹
> - **原始字符串（r"路径"）**：在字符串前面加`r`，让`\`不被当成转义字符，写Windows路径时必须用
> - **转义字符**：`\n`表示换行，`\t`表示制表符，`\\`表示一个反斜杠

**绝对路径**：
```python
# Windows绝对路径（从盘符开始，必须用双反斜杠\\）
file_path = "C:\\Users\\Admin\\Documents\\data.txt"
# 或用原始字符串（推荐！r让\不转义）
file_path = r"C:\Users\Admin\Documents\data.txt"

# 读取文件
with open(file_path, "r", encoding="utf-8") as f:
    content = f.read()
```

**相对路径**：
```python
# 当前目录下的文件（最简单）
file_path = "data.txt"  # 当前文件夹里的data.txt

# 子目录（当前文件夹下的data文件夹）
file_path = "data/input.txt"  # 斜杠/表示进入子文件夹

# 上级目录（上一级文件夹）
file_path = "../config.txt"  # ..表示往上走一级

# 读取文件
with open(file_path, "r", encoding="utf-8") as f:
    content = f.read()
```

**相对路径符号**：
```python
# . 表示当前目录（可以省略不写）
"./data.txt"  # 当前目录下的data.txt（和"data.txt"完全一样）

# .. 表示上级目录
"../data.txt"      # 上一级目录里的data.txt
"../../data.txt"   # 上两级目录里的data.txt

# 组合使用
"./data/input.txt"          # 当前目录→data文件夹→input.txt
"../config/settings.json"   # 上级目录→config文件夹→settings.json
```

**AI开发场景**：
```python
# 场景1：读取配置文件（相对路径，项目内通用）
with open("config/api_config.json", "r", encoding="utf-8") as f:
    config = json.load(f)

# 场景2：保存处理结果（相对路径，输出到项目内）
with open("output/result.txt", "w", encoding="utf-8") as f:
    f.write("处理完成")

# 场景3：读取固定位置的文件（绝对路径，系统级位置）
log_file = r"D:\logs\app.log"  # 用r前缀避免转义问题
with open(log_file, "a", encoding="utf-8") as f:
    f.write("程序启动\n")
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `FileNotFoundError` | 路径写错了或文件不存在 | 检查路径拼写，确认文件存在 |
| Windows路径反斜杠报错 | `\U` `\A`被当成转义字符 | 用原始字符串`r"C:\path"`或双反斜杠`\\` |
| 相对路径找不到文件 | 当前工作目录不对 | 用绝对路径或先切换目录 |
| 路径拼接用字符串相加 | `"folder" + "file.txt"`变成`"folderfile.txt"` | 用`os.path.join()` |

### ⑤ 精简背诵笔记

```
【绝对路径与相对路径】
✓ 绝对路径：从盘符开始（C:\Users\...）
✓ 相对路径：从当前目录开始（./data/file.txt）
✓ . 当前目录，.. 上级目录
✓ Windows路径用原始字符串 r"路径"
✓ AI开发：配置文件用相对路径，日志用绝对路径
✓ 路径拼接用os.path.join()，不要用+号
```

## 【补充】知识点 5.5：os模块路径操作

### ① 一句话通俗定义
**os模块路径操作 = Python提供的路径处理工具，解决跨平台路径问题。**

### ② 生活例子类比
os.path就像**导航软件**：
- 帮你拼接路径（不用手动加斜杠）
- 判断路径是否存在（不用自己检查）
- 自动适配系统（Windows用`\`，Mac/Linux用`/`）

AI应用开发中，文件路径处理必须用os模块，否则跨平台时会出问题。

### ③ 语法说明

> 📌 **专业术语解释**：
> - **os模块**：Python内置的操作系统接口模块，提供文件和目录操作功能
> - **os.path**：os模块下的路径处理子模块，专门处理文件路径
> - **路径拼接**：把多个路径片段组合成一个完整路径（比如"project" + "data" → "project/data"）
> - **跨平台**：同样的代码在Windows、Mac、Linux上都能运行

**os.path.join()：拼接路径（最常用）**
```python
import os  # 必须先导入os模块

# 手动拼接（容易出错！不推荐）
path1 = "data" + "/" + "input.txt"  # data/input.txt
path2 = "data" + "\\" + "input.txt"  # data\input.txt（Windows专用）

# 用os.path.join（推荐！自动适配系统）
path = os.path.join("data", "input.txt")
print(path)  # Windows: data\input.txt  Mac/Linux: data/input.txt

# 多层拼接（不管多少层都能拼）
path = os.path.join("project", "data", "input", "file.txt")
print(path)  # project/data/input/file.txt（自动加斜杠）

# AI开发场景：构建文件路径
base_dir = "ai_project"
config_file = os.path.join(base_dir, "config", "settings.json")
print(config_file)  # ai_project/config/settings.json
```

**os.path.exists()：判断路径是否存在**
```python
import os

# 判断文件是否存在
if os.path.exists("data.txt"):
    print("文件存在")
else:
    print("文件不存在")

# 判断文件夹是否存在
if os.path.exists("data_folder"):
    print("文件夹存在")

# AI开发场景：读取前检查文件（避免报错）
config_path = "config/api.json"
if not os.path.exists(config_path):  # not = 不存在
    print(f"配置文件不存在：{config_path}")
else:
    with open(config_path, "r", encoding="utf-8") as f:
        config = json.load(f)
```

**os.path常用方法**：
```python
import os

path = "data/input/file.txt"

# 获取文件名（去掉路径，只留文件名）
filename = os.path.basename(path)
print(filename)  # file.txt

# 获取目录名（去掉文件名，只留路径）
dirname = os.path.dirname(path)
print(dirname)  # data/input

# 分离文件名和扩展名
name, ext = os.path.splitext("file.txt")
print(name)  # file（文件名）
print(ext)   # .txt（扩展名）

# 判断是否是文件/目录
print(os.path.isfile("data.txt"))  # True（是文件）
print(os.path.isdir("data"))       # True（是目录）
```

## 【补充】知识点 5.6：文件编码规范

### ① 一句话通俗定义
**文件编码规范 = 读写文件时必须指定encoding="utf-8"，避免中文乱码。**

### ② 生活例子类比
编码就像**语言翻译**：
- UTF-8 = 国际通用语言（所有系统都懂）
- GBK = 中文专用语言（只有中文系统懂）
- 不指定编码 = 用系统默认语言（Windows中文用GBK，可能乱码）

AI应用开发中，处理中文文本必须统一用UTF-8，否则乱码。

### ③ 语法说明

> 📌 **专业术语解释**：
> - **编码（Encoding）**：文字转成计算机能懂的数字的规则，不同编码规则不一样
> - **UTF-8**：国际通用编码，支持所有语言文字（中文、英文、日文等）
> - **GBK**：中文Windows系统的默认编码，只支持中文和英文
> - **解码（Decode）**：把计算机里的数字转回文字的过程
> - **UnicodeDecodeError**：解码失败错误，说明用错了编码规则

**正确写法：始终指定encoding**
```python
# ✅ 正确：读写都指定encoding="utf-8"（必须写！）
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("你好世界")

with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)  # 正常显示：你好世界

# ❌ 错误：不指定encoding（Windows可能乱码）
with open("data.txt", "w") as f:
    f.write("你好世界")

with open("data.txt", "r") as f:
    content = f.read()
    print(content)  # 可能显示乱码：锟斤拷锟斤拷
```

**为什么必须指定UTF-8**
```python
# Windows默认编码是GBK（中文系统）
# Python默认编码是UTF-8
# 不指定encoding时，open()用系统默认编码（Windows是GBK）

# 场景：用UTF-8写入，用GBK读取（会乱码）
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("你好")  # 用UTF-8规则存到文件

# 用GBK读取（用错规则，就会乱码）
with open("test.txt", "r", encoding="gbk") as f:
    content = f.read()
    print(content)  # 显示乱码

# 正确：用UTF-8读取（写入和读取用同一个规则）
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)  # 正常显示：你好
```

```python
import json
import os

def save_ai_response(response, output_file):
    """保存AI回答到文件"""
    with open(output_file, "w", encoding="utf-8") as f:
        # json.dump()把字典转成JSON字符串写入文件
        # ensure_ascii=False：允许保存中文（不然中文会变成Unicode编码）
        # indent=2：格式化输出，好看
        json.dump(response, f, ensure_ascii=False, indent=2)
    print(f"已保存到：{output_file}")

def load_training_data(data_file):
    """加载训练数据"""
    # 先检查文件是否存在
    if not os.path.exists(data_file):
        print(f"文件不存在：{data_file}")
        return []  # 返回空列表
    
    # 用UTF-8读取
    with open(data_file, "r", encoding="utf-8") as f:
        return json.load(f)  # 把JSON字符串转成Python字典

def process_text_file(input_file, output_file):
    """处理文本文件"""
    # ① 读取（指定UTF-8）
    with open(input_file, "r", encoding="utf-8") as f:
        lines = f.readlines()
    
    # ② 处理每一行
    processed = []
    for line in lines:
        cleaned = line.strip().lower()  # 去空格、转小写
        if cleaned:  # 如果不是空行（空字符串是False）
            processed.append(cleaned)
    
    # ③ 保存（指定UTF-8）
    with open(output_file, "w", encoding="utf-8") as f:
        for line in processed:
            f.write(line + "\n")  # 写入一行，加换行符
    
    print(f"处理完成：{len(processed)}行")

# 使用示例
```
