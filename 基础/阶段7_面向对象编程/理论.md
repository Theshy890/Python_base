# 阶段7：代码的"乐高积木"——面向对象编程

> 阶段目标：掌握类、继承、多态，能把相关功能打包成一个"对象"
> 在AI应用开发中的作用：封装AI模型调用、管理对话状态、统一接口设计

---

## 知识点 7.1：什么是面向对象编程

### ① 一句话通俗定义
**面向对象编程 = 把数据和操作数据的方法打包在一起，形成一个"对象"。**

就像一辆汽车：它有颜色、速度这些"数据"，也有启动、刹车这些"方法"，它们都属于同一个"汽车对象"。

### ② 生活例子类比

| 面向过程 | 面向对象 |
|---------|---------|
| 修车：先找轮子，再找发动机，再组装 | 修车：直接找"汽车"这个整体，它自己知道怎么修 |
| 点菜：先点鱼，再点米饭，再点汤 | 点菜：点"套餐"，套餐里已经包含了所有搭配 |

### ③ AI开发场景
| 场景 | 对象化设计 |
|------|-----------|
| 调用不同AI模型 | 创建一个"AI模型"类，不同模型继承它 |
| 管理对话历史 | 创建一个"对话"类，包含历史记录和方法 |
| 配置管理 | 创建一个"配置"类，统一管理参数 |

## 知识点 7.2：class定义——创建自己的数据类型

### ① 一句话通俗定义
**class = 定义一个新的"数据类型"的蓝图。**

就像建筑图纸：图纸上画好了房子的结构（有几个房间、多大面积），按照图纸就能盖出具体的房子。

### ② 语法说明

```python
# 定义一个"AI模型"类
class AIModel:
    def __init__(self, model_name, api_key):
        # __init__：构造方法，创建对象时自动调用
        # self：代表当前对象本身（类似中文的"我"）
        self.model_name = model_name  # 对象属性：模型名称
        self.api_key = api_key        # 对象属性：API密钥
        self.temperature = 0.7        # 默认属性：温度参数

    def generate(self, prompt):
        # 对象方法：生成AI回复
        print(f"[{self.model_name}] 正在处理：{prompt}")
        return f"AI回答：{prompt} 的结果"

    def set_temperature(self, temp):
        # 对象方法：设置温度参数
        if 0 <= temp <= 1:
            self.temperature = temp
            print(f"温度已设置为：{temp}")
        else:
            print("温度必须在0-1之间")

# 创建对象（实例化）
model = AIModel("GPT-3", "sk-123456")

# 调用对象方法
result = model.generate("你好")
print(result)

# 修改对象属性
model.set_temperature(0.9)
print(f"当前温度：{model.temperature}")
```

### ③ 类的组成

| 组成部分 | 说明 | 类比 |
|---------|------|------|
| `class` | 定义类的关键字 | 建筑图纸的标题 |
| `__init__` | 构造方法，初始化对象 | 房子建好后装修 |
| `self` | 代表当前对象 | 房子里的"我" |
| `self.属性名` | 对象的属性（数据） | 房子的面积、颜色 |
| `def 方法名(self)` | 对象的方法（操作） | 房子的开门、关灯 |

## 知识点 7.3：私有属性——保护敏感数据

### ① 一句话通俗定义
**私有属性 = 只能在类内部使用，外部不能直接访问的属性。**

就像你的银行卡密码：只能你自己用，别人不能直接查。

### ② 语法说明

```python
class AIModel:
    def __init__(self, model_name, api_key):
        self.model_name = model_name  # 公开属性
        self.__api_key = api_key      # 私有属性（__开头）

    def get_api_key_masked(self):
        # 提供一个方法，返回脱敏后的API密钥
        return self.__api_key[:4] + "****" + self.__api_key[-4:]

# 创建对象
model = AIModel("GPT-3", "sk-abcdefghijklmnop")

# 可以访问公开属性
print(model.model_name)  # GPT-3

# 不能直接访问私有属性（会报错）
# print(model.__api_key)  # AttributeError

# 通过方法访问
print(model.get_api_key_masked())  # sk-ab****mnop
```

**为什么用私有属性**：
- 保护敏感数据（如API密钥）
- 控制属性的读写权限
- 避免外部意外修改内部状态

## 知识点 7.4：继承——站在巨人的肩膀上

### ① 一句话通俗定义
**继承 = 一个类可以继承另一个类的属性和方法。**

就像儿子继承父亲的财产和技能：儿子天生就有父亲的某些能力，但也可以发展自己的特长。

### ② 语法说明

```python
# 父类：基础AI模型
class AIModel:
    def __init__(self, model_name, api_key):
        self.model_name = model_name
        self.__api_key = api_key

    def generate(self, prompt):
        return f"[{self.model_name}] 生成结果"

# 子类：Chat模型（继承AIModel）
class ChatModel(AIModel):
    def __init__(self, model_name, api_key, max_tokens):
        # super()：调用父类的构造方法
        super().__init__(model_name, api_key)
        self.max_tokens = max_tokens  # 子类特有属性

    def generate(self, prompt, history=None):
        # 重写父类方法（多态）
        if history is None:
            history = []
        print(f"使用历史对话：{history}")
        return f"[{self.model_name}] 对话生成：{prompt}（最多{self.max_tokens}token）"

# 创建子类对象
chat = ChatModel("GPT-4", "sk-123456", 4096)

# 继承父类属性
print(chat.model_name)  # GPT-4

# 使用子类方法（重写后的）
result = chat.generate("你好", [("用户", "你好"), ("AI", "你好！")])
print(result)
```

### ③ 继承的好处

| 好处 | 说明 |
|------|------|
| 代码复用 | 父类的代码不用重复写 |
| 层次清晰 | 子类专注于自己的特殊功能 |
| 易于扩展 | 新增功能只需要加子类 |

## 知识点 7.5：多态——同一个方法，不同的表现

### ① 一句话通俗定义
**多态 = 同一个方法名，在不同类中有不同的实现。**

就像"说话"这个动作：中国人说中文，英国人说英文，但都叫"说话"。

### ② 语法说明

```python
class AIModel:
    def generate(self, prompt):
        pass  # 父类定义方法，但不实现

class GPTModel(AIModel):
    def generate(self, prompt):
        return f"GPT回复：{prompt}"

class ClaudeModel(AIModel):
    def generate(self, prompt):
        return f"Claude回复：{prompt}"

# 使用多态
def call_model(model, prompt):
    # 不管是哪种模型，都用同一个方法名
    result = model.generate(prompt)
    print(result)

gpt = GPTModel()
claude = ClaudeModel()

call_model(gpt, "你好")     # GPT回复：你好
call_model(claude, "你好")  # Claude回复：你好
```

**多态的好处**：调用者不需要关心具体是哪个类，统一接口，方便替换。

## 知识点 7.6：property装饰器——更优雅的属性访问

### ① 一句话通俗定义
**property = 把方法变成属性一样访问。**

就像你问"今天天气怎么样"，背后其实是气象台在计算，但你只需要简单问一句。

### ② 语法说明

```python
class AIModel:
    def __init__(self, api_key):
        self.__api_key = api_key

    @property
    def api_key_masked(self):
        # 把方法变成属性（只读）
        return self.__api_key[:4] + "****" + self.__api_key[-4:]

model = AIModel("sk-abcdefghijklmnop")

# 像访问属性一样访问方法（不用加括号）
print(model.api_key_masked)  # sk-ab****mnop
```

**什么时候用**：需要对属性访问做额外处理，但又想保持简洁的访问方式。

## 知识点 7.7：AI开发实战——封装AI模型调用

### 场景：统一管理多个AI服务

```python
class BaseAI:
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = "https://api.example.com"

    def _make_request(self, endpoint, data):
        # 通用请求方法（下划线开头表示内部方法）
        print(f"请求 {self.base_url}{endpoint}，数据：{data}")
        return {"success": True, "data": "模拟响应"}

class OpenAIModel(BaseAI):
    def __init__(self, api_key):
        super().__init__(api_key)
        self.base_url = "https://api.openai.com/v1"

    def chat_completion(self, messages):
        data = {
            "model": "gpt-3.5-turbo",
            "messages": messages,
            "api_key": self.api_key
        }
        return self._make_request("/chat/completions", data)

class ClaudeModel(BaseAI):
    def __init__(self, api_key):
        super().__init__(api_key)
        self.base_url = "https://api.anthropic.com/v1"

    def chat_completion(self, messages):
        data = {
            "model": "claude-3-sonnet",
            "messages": messages,
            "api_key": self.api_key
        }
        return self._make_request("/messages", data)

# 使用
openai = OpenAIModel("sk-123456")
claude = ClaudeModel("sk-abcdef")

response1 = openai.chat_completion([{"role": "user", "content": "你好"}])
response2 = claude.chat_completion([{"role": "user", "content": "你好"}])

print(response1)  # {'success': True, 'data': '模拟响应'}
print(response2)  # {'success': True, 'data': '模拟响应'}
```

### 场景：管理对话状态

```python
class ChatSession:
    def __init__(self, model):
        self.model = model
        self.history = []

    def add_message(self, role, content):
        self.history.append({"role": role, "content": content})

    def get_response(self, user_input):
        # 添加用户消息
        self.add_message("user", user_input)

        # 调用模型
        response = self.model.chat_completion(self.history)

        # 添加AI回复
        ai_reply = "AI的回复内容"
        self.add_message("assistant", ai_reply)

        return ai_reply

    def clear_history(self):
        self.history = []
        print("对话历史已清空")

# 使用
session = ChatSession(openai)
reply1 = session.get_response("你好")
reply2 = session.get_response("什么是AI？")
print(f"对话历史长度：{len(session.history)}")  # 4（2条用户+2条AI）
session.clear_history()
```

## 总结

| 知识点 | 核心内容 | AI开发用途 |
|--------|---------|-----------|
| class定义 | 创建自定义数据类型 | 封装AI模型、对话等 |
| __init__ | 构造方法，初始化对象 | 设置初始参数 |
| self | 代表当前对象 | 访问对象属性和方法 |
| 私有属性 | __前缀，保护数据 | 隐藏API密钥等敏感信息 |
| 继承 | 子类继承父类功能 | 统一不同AI服务接口 |
| 多态 | 同一方法不同实现 | 灵活替换模型 |
| property | 方法变属性 | 优雅的属性访问 |

面向对象编程让你的代码更**结构化、可维护、可扩展**，是开发大型AI应用的必备技能！
