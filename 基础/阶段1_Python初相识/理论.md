## 知识点 1.1：print() 打印输出

### ① 一句话通俗定义
**print() = 让程序"说话"，把你想展示的内容显示在屏幕上。**

### ② 生活例子类比
print()就像**大喇叭广播**。你对着喇叭喊一句话（括号里的内容），喇叭就会把这句话播出去让所有人听到。AI应用开发中，调试代码时经常用print()看看"程序跑到哪一步了、中间结果是什么"。

### ③ 语法说明

```python
print(内容)              # 打印一个内容
print(内容1, 内容2)       # 打印多个内容，自动用空格隔开
print("文字")             # 打印文字（必须加引号）
print(100)               # 打印数字（不加引号）
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `SyntaxError: invalid syntax` | 括号用了中文括号（） | 改成英文括号() |
| `SyntaxError: EOL while scanning string literal` | 引号没闭合，或中英文引号混用 | 检查引号成对出现，全部用英文引号 |
| 打印文字没加引号，报错`name 'xxx' is not defined` | print里的文字必须用引号包起来 | `print("你好")` 而不是 `print(你好)` |
| 想打印数字但加了引号变成字符串 | 引号里的内容会被当成"文字"而非"数字" | 数字不加引号：`print(100)` |

### ⑤ 分层练习题

**入门基础题**：写一个程序，打印出你的名字、年龄、城市，每个信息一行。

**进阶综合题**：用print打印出下面这个图案（注意换行）：
```
*
**
***
****
```

**简易数据处理实战题**：假设你在做一个AI文本处理项目，用print模拟输出一条日志信息，格式如下：
```
[2026-07-18] 任务：文本清洗 | 状态：开始执行
```

### ⑥ 精简背诵笔记

```
【print() 打印】
✓ 作用：把内容输出到屏幕
✓ 语法：print(内容)
✓ 文字必须加引号："文字" 或 '文字'
✓ 数字不加引号：print(100)
✓ 多个内容用逗号隔开：print(a, b, c)
✓ 换行符：\n
✓ 调试神器：程序出问题时，到处print看中间结果
```

## 知识点 1.2：注释

### ① 一句话通俗定义
**注释 = 写给"人"看的笔记，Python会自动忽略它，不会执行。**

### ② 生活例子类比
注释就像你在菜谱上写的**便利贴**："这一步要小火"、"这里可以加糖"。做饭的人（你）看得到，但锅（Python）看不懂也不关心。写注释是为了让自己或别人以后看代码时能看懂。

###  语法说明

```python
# 这是单行注释，用#开头

print("这行会被执行")  # 这行注释在代码后面

# 下面的多行注释用三个引号包起来
"""
这是多行注释
可以写很多行
Python会完全忽略
"""

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| 注释后面的代码也被"注释掉"了 | 多行注释的引号没闭合 | 检查`"""`是否成对出现 |
| `#`后面的中文显示乱码 | 文件编码不是UTF-8 | 在文件第一行加 `# -*- coding: utf-8 -*-` |
| 把注释当代码执行 | 注释不会被执行，这是正常现象 | 想执行就去掉`#` |

### ⑤ 精简背诵笔记

```
【注释】
✓ 单行注释：# 内容
✓ 多行注释：""" 内容 """
✓ 作用：给人看，Python不执行
✓ 好习惯：关键代码都要写注释
```

## 知识点 1.3：变量

### ① 一句话通俗定义
**变量 = 一个带标签的盒子，用来装数据，以后可以通过标签名找到里面的东西。**

### ② 生活例子类比
变量就像**搬家时的纸箱**：
- 纸箱 = 变量本身
- 纸箱上贴的标签"书籍"、"衣服" = 变量名
- 纸箱里装的东西 = 变量的值

AI应用开发中，用户输入的文字、AI返回的结果、处理过程中的中间数据，全都要装进"变量盒子"里，随时取用。

### ③ 语法说明

```python
# 创建变量（创建盒子并贴标签）
name = "小明的AI助手"
age = 1
message = "你好，我是AI助手"

# 使用变量（通过标签名取盒子里的东西）
print(name)
print(age)
print(message)

# 变量可以重新赋值（换盒子里的东西）
age = 2
print(age)  # 输出2，不再是1
```

**变量命名规则**：
```python
# ✅ 正确的命名
user_name = "张三"     # 推荐：小写字母+下划线
age1 = 25              # 可以包含数字（但不能以数字开头）
_private = "秘密"      # 可以以下划线开头

# ❌ 错误的命名
# 2age = 25            # 不能以数字开头
# user-name = "张三"   # 不能用减号
# class = "一班"       # 不能用Python保留字（如class、if、for等）
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `NameError: name 'xxx' is not defined` | 使用了没定义过的变量，或变量名拼写错误 | 检查变量名是否创建过，拼写是否一致 |
| 赋值用了一个等号`=`，误写成两个`==` | `=`是赋值，`==`是比较是否相等 | 赋值用单等号 |
| 变量名用了中文 | 虽然Python3支持中文变量名，但不推荐 | 用英文小写+下划线 |
| 变量值被意外覆盖 | 同名变量会被后面的赋值覆盖 | 注意变量名不要重复使用 |

### ⑤ 分层练习题

**入门基础题**：创建3个变量，分别存储你的姓名、年龄、城市，然后打印出来。

**进阶综合题**：
```python
a = 10
b = 20
# 请交换a和b的值（不直接写a=20, b=10）
# 提示：可以用第三个变量temp作为"临时中转盒"
```

**简易数据处理实战题**：模拟AI文本处理场景，创建变量存储"原始文本"、"处理后的文本"、"处理状态"，打印出处理报告。

### ⑥ 精简背诵笔记

```
【变量】
✓ 定义：变量名 = 值
✓ 命名规则：字母/下划线开头，由字母数字下划线组成
✓ 不能用Python保留字（if、for、class等）
✓ 推荐命名：小写+下划线（user_name）
✓ 赋值用 = ，比较用 ==
✓ 变量可重新赋值，新值覆盖旧值
```

## 知识点 1.4：四大基本数据类型

### ① 一句话通俗定义
**数据类型 = 盒子里装的东西的"种类"，不同种类能做不同的事。**

### ② 生活例子类比
数据类型就像**超市里的商品分类**：
- **整数（int）** = 计数商品，如"3个苹果"，只能整个数
- **小数（float）** = 称重商品，如"1.5斤肉"，有零有整
- **字符串（str）** = 文字标签，如包装上的说明文字
- **布尔值（bool）** = 开关，只有"开/关"两种状态

AI应用开发中，AI返回的数字是int/float，返回的文字是str，判断"是否成功"用bool。搞错类型会让程序出错。

###  语法说明

```python
# 整数 int

user_count = 100
print(type(user_count))  # <class 'int'>

# 小数 float
price = 9.9
print(type(price))  # <class 'float'>

# 字符串 str（用引号包起来）
text = "你好AI"
print(type(text))  # <class 'str'>

# 布尔值 bool（只有True和False两个值）
is_running = True
is_error = False
print(type(is_error))  # <class 'bool'>
```

**查看类型的神器：type()**
```python
print(type(100))      # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
print(type(True))     # <class 'bool'>
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| 把数字当字符串用，如`"100" + 50`报错 | 引号里的"100"是字符串，不能和数字相加 | 去掉引号变数字，或用类型转换 |
| True/False首字母没大写 | Python里布尔值必须首字母大写 | `True` `False`，不是`true` `false` |
| 除法结果变成float | Python3中`/`除法结果自动是float | 要整数用`//`（整除）：`10//3`得3 |
| 混淆`=`和`==` | `=`赋值，`==`比较 | 赋值用=，判断相等用== |

### ⑤ 分层练习题

**入门基础题**：分别创建int、float、str、bool类型的变量各一个，用type()打印出它们的类型。

**进阶综合题**：不用type()，你能看出下面这些值分别是什么类型吗？先猜再验证。
```python
a = "123"
b = 123
c = 123.0
d = True
e = "True"

```

**简易数据处理实战题**：模拟AI接口返回的数据，创建变量存储：用户提问次数（int）、响应时间（float）、回答内容（str）、是否成功（bool），打印每个数据的类型。

### ⑥ 精简背诵笔记

```
【四大基本数据类型】
✓ int 整数：100, -5, 0
✓ float 小数：3.14, -0.5, 2.0
✓ str 字符串："文字", '文字'（必须带引号）
✓ bool 布尔值：True, False（首字母必须大写）
✓ 查看类型：type(值)
✓ 字符串和数字不能直接混合运算
```

## 知识点 1.5：输入 input()

### ① 一句话通俗定义
**input() = 让程序"停下来问你"，等你输入内容后，把内容存进变量。**

### ② 生活例子类比
input()就像**自动售货机**：
- 机器问你"要什么饮料？"（input提示）
- 你按下按钮选择（用户输入）
- 机器把你选的东西给你（存入变量）

AI应用开发中，用户输入的问题、选择的选项，都用input()接收，然后交给AI处理。

### ③ 语法说明

```python
# 基本用法
name = input("请输入你的名字：")
print("你好，" + name)

# input()接收的内容永远是字符串类型
age = input("请输入年龄：")
print(type(age))  # 即使输入25，输出也是 <class 'str'>
```

###  新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `input()`接收的数字不能直接做数学运算 | input()返回的永远是字符串 | 用int()或float()转换类型 |
| 程序"卡住"不动 | input()在等你输入，输入完按回车 | 输入内容后按回车键 |
| 提示文字没显示 | 忘记在input()括号里写提示语 | `input("提示：")` |

### ⑤ 分层练习题

**入门基础题**：写程序，让用户输入姓名和城市，打印出"XXX来自XXX"。

**进阶综合题**：写一个简单的"AI问候机器人"，用户输入名字，程序打印"你好，[名字]！我是AI助手，很高兴认识你。"

**简易数据处理实战题**：模拟"文本长度检测工具"——用户输入一段文字，程序打印出这段文字的长度（用`len()`函数）。

### ⑥ 精简背诵笔记

```
【input() 输入】
✓ 语法：变量 = input("提示文字")
✓ 返回值永远是字符串str类型
✓ 要做数学运算需先转类型：int(input())
```

## 知识点 1.6：类型转换

### ① 一句话通俗定义
**类型转换 = 把一种数据类型"变身"成另一种，让不兼容的数据能一起运算。**

### ② 生活例子类比
类型转换就像**货币兑换**：
- 人民币（str）不能直接在美国花，要换成美元（int）
- 字符串"100"是"文字形式的100"，不能做数学
- 用int()把"100"换成真正的数字100，就能做加减乘除了

AI应用开发中，用户输入的是字符串，AI返回的可能是JSON字符串，都要转换类型才能处理。

### ③ 语法说明

```python
# 字符串 → 整数
age_str = "25"
age_int = int(age_str)
print(age_int + 5)  # 输出30

# 字符串 → 小数
price_str = "9.9"
price_float = float(price_str)
print(price_float * 2)  # 输出19.8

# 数字 → 字符串
age = 25
message = "我今年" + str(age) + "岁"
print(message)

# 整数 → 小数
print(float(10))  # 输出10.0

# 小数 → 整数（直接砍掉小数部分，不四舍五入！）
print(int(9.9))  # 输出9，不是10！

# 任何类型 → 布尔值
print(bool(0))       # False（0是False）
print(bool(100))     # True（非0是True）
print(bool(""))      # False（空字符串是False）
print(bool("hello")) # True（非空字符串是True）
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `ValueError: invalid literal for int()` | 字符串里不是纯数字，如`int("abc")`或`int("12.5")` | 确保字符串内容是纯整数 |
| `int(9.9)`得到9不是10 | int()直接砍小数部分，不四舍五入 | 要四舍五入用`round(9.9)` |
| 字符串拼接用`+`但混了数字 | `"年龄：" + 25`会报错 | 数字先转字符串：`"年龄：" + str(25)` |

### ⑤ 分层练习题

**入门基础题**：完成以下转换并打印结果：
- 把字符串"2026"转成整数
print(int("2026"))
- 把整数100转成字符串
print(str(100))
- 把小数3.14转成整数
print(int(3.14))

**进阶综合题**：写一个"年龄计算器"——用户输入出生年份（如2000），程序计算出年龄并打印"你今年XX岁"。（提示：用2026减去出生年份）

**简易数据处理实战题**：模拟AI接口返回的"响应时间"是字符串"1.25"，把它转成小数，计算3次请求的总耗时。

###  精简背诵笔记

```
【类型转换】
✓ int(x) → 整数（小数直接砍尾，不四舍五入）
✓ float(x) → 小数
✓ str(x) → 字符串
✓ bool(x) → 布尔值（0/空为False，其他为True）
✓ 转换前提：内容必须合法，如int("abc")会报错
✓ 四舍五入用 round(x)
```

## 知识点 1.7：基础运算符

### ① 一句话通俗定义
**运算符 = 对数据做"加减乘除"等操作的符号，就像计算器上的按钮。**

### ② 生活例子类比
运算符就像**厨房里的工具**：
- `+` `-` `*` `/` 是"切菜、炒菜"的基础工具
- `//` `%` `**` 是"特殊模具"，做特定形状的菜
- AI应用开发中，统计字数、计算相似度、分割文本，全靠运算符

###  语法说明

```python
# 算术运算符
print(10 + 3)   # 13 加
print(10 - 3)   # 7  减
print(10 * 3)   # 30 乘
print(10 / 3)   # 3.333... 除（结果是float）
print(10 // 3)  # 3  整除（只取整数部分）
print(10 % 3)   # 1  取余数（10除以3余1）
print(10 ** 3)  # 1000 幂运算（10的3次方）

# 字符串的"加法"和"乘法"
print("你好" + "世界")   # 你好世界（字符串拼接）
print("加油" * 3)        # 加油加油加油（字符串重复）

# 比较运算符（结果是bool布尔值）
print(10 > 5)    # True
print(10 == 5)   # False（==判断相等）
print(10 != 5)   # True（!=判断不相等）
print(10 >= 10)  # True

# 赋值运算符：+=（累加简写）
count = 0
count = count + 1  # 普通写法
count += 1         # 简写，效果一样（count变成2）
# 同理：-= *= /= 都是简写
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `/`除法结果是3.333不是3 | Python3的`/`总是返回float | 要整数用`//` |
| 字符串相加报错 | `"100" + 50`类型不匹配 | 先转同类型：`int("100") + 50` |
| `=`和`==`搞混 | `=`赋值，`==`比较 | 判断相等用两个等号`==` |
| `**`优先级问题 | `2**3`是8，但`-2**2`是-4不是4 | 负数幂加括号：`(-2)**2` |

### ⑤ 分层练习题

**入门基础题**：计算并打印：
- 100除以3的商和余数

- 2的10次方

- 字符串"AI"重复5次

**进阶综合题**：已知一个AI接口每次调用费用0.002元，预算100元，最多能调用多少次？剩余多少钱？（用整除和取余）

**简易数据处理实战题**：一段文本有256个字符，AI模型每次最多处理100个字符，需要分几次处理？最后一次处理几个字符？

### ⑥ 精简背诵笔记

```
【基础运算符】
✓ 算术：+ - * /（除，得float） //（整除） %（取余） **（幂）
✓ 字符串：+ 拼接，* 重复
✓ 比较：> < >= <= ==（相等） !=（不等）
✓ 赋值简写：+= -= *= /=（count += 1 等于 count = count + 1）
✓ 比较结果是bool：True或False
✓ 优先级：** > * / // % > + -
```

## 知识点 1.8：f-string 格式化字符串

### ① 一句话通俗定义
**f-string = 一种"填空式"的字符串写法，把变量直接塞进字符串里，不用拼来拼去。**

### ② 生活例子类比
f-string就像**填空题**：
- 普通写法：`"我今年" + str(25) + "岁"` → 像把几个纸条粘在一起，麻烦
- f-string写法：`f"我今年{25}岁"` → 像填空题，`{}`里直接填答案，简洁

AI应用开发中，拼prompt、拼日志、拼输出信息，f-string是最常用的写法。

### ③ 语法说明

```python
# 基本用法：字符串前面加 f，变量放进 {}
name = "张三"
age = 25
print(f"我叫{name}，今年{age}岁")  # 我叫张三，今年25岁

# {}里可以放表达式
a = 10
b = 3
print(f"{a}除以{b}等于{a/b:.2f}")  # 10除以3等于3.33（:.2f表示保留2位小数）

# 字典取值（注意：外层用双引号，里面用单引号）
user = {"name": "张三", "score": 90}
print(f"姓名：{user['name']}，分数：{user['score']}")

# 对比三种写法（效果一样，f-string最简洁）
name = "AI"
# 写法1：+ 拼接
print("你好，" + name)
# 写法2：逗号分隔
print("你好，", name)
# 写法3：f-string（推荐）
print(f"你好，{name}")
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| 忘记在字符串前加`f` | `"{name}"`不会替换变量，原样输出 | 加`f`：`f"{name}"` |
| f-string里用双引号嵌套双引号 | `f"他说"你好""`会报错 | 外层双引号，里面用单引号：`f'他说"你好"'` |
| `{}`里写复杂表达式看不懂 | 太复杂不利于阅读 | 复杂计算先存变量，再放进`{}` |

###  精简背诵笔记

```
【f-string 格式化字符串】
✓ 语法：f"文字{变量}文字"
✓ 字符串前必须加 f
✓ {}里放变量名或表达式
✓ 格式化小数：{值:.2f}（保留2位小数）
✓ 字典取值：{dict['key']}（外层用双引号，里面用单引号）
✓ AI开发中最推荐的字符串拼接方式
```

## 知识点 1.9：字符串基础方法

### ① 一句话通俗定义
**字符串方法 = 字符串自带的"小工具"，可以对文字做清洗、转换等操作。**

### ② 生活例子类比
字符串方法就像**文字处理器的按钮**：
- `.strip()` = "去空格"按钮，去掉文字前后的空格
- `.lower()` = "转小写"按钮
- `.upper()` = "转大写"按钮

AI应用开发中，用户输入的文字经常有前后空格、大小写混乱，调用AI之前要先清洗，这三个方法是最常用的。

### ③ 语法说明

```python
# .strip()：去掉字符串前后的空格和换行符
text = "  Hello World  "
print(text.strip())  # "Hello World"

# .lower()：转成全部小写
print("PYTHON".lower())  # "python"

# .upper()：转成全部大写
print("hello".upper())  # "HELLO"

# 可以链式调用（一个接一个）
text = "  Hello World  "
print(text.strip().lower())  # "hello world"

# AI开发中的典型用法：清洗用户输入
user_input = "  帮我翻译 Hello  "
cleaned = user_input.strip()
print(f"清洗后：'{cleaned}'")
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `text.strip()`后原变量没变 | 字符串方法返回新字符串，不修改原变量 | 要赋值回去：`text = text.strip()` |
| `.strip()`只去前后空格 | 中间的空格不会去掉 | 中间空格用`.replace(" ", "")` |
| 忘记加括号 | `text.strip`不执行 | 方法必须加括号：`text.strip()` |

### ⑤ 精简背诵笔记

```
【字符串基础方法】
✓ .strip()：去前后空格/换行
✓ .lower()：转小写
✓ .upper()：转大写
✓ 可以链式调用：text.strip().lower()
✓ 不修改原字符串，返回新字符串
✓ AI开发中文本清洗必备
```

## 【补充】知识点 1.10：PEP8代码规范

### ① 一句话通俗定义
**PEP8 = Python官方推荐的"代码书写规范"，让你的代码整齐、易读、专业。**

### ② 生活例子类比

### ③ 语法说明

**变量命名规则**：

```

```python
# 单行注释：# 后面加空格
name = "AI助手"  # 行尾注释也要加空格

def call_ai_api(prompt):
    """
    调用AI接口获取回答
    
    参数：
        prompt: 用户提问内容
    
    返回：
        AI的回答文本

```

**空格规范**：
```python
# ✅ 正确

# ❌ 错误

```

**禁止使用关键字做变量名**：
```python

# if = 10        # 错误
# for = "abc"    # 错误
# class = "一班"  # 错误

# Python关键字列表（部分）：

```

### ⑤ 精简背诵笔记

```

✓ 单行注释：# 后面加空格

## 【补充】知识点 1.11：完整运算符体系

### ① 一句话通俗定义
**完整运算符 = Python所有操作符号的集合，包括赋值、比较、逻辑运算等。**

### ② 生活例子类比
运算符就像**工具箱里的各种工具**：
- 算术运算符（+ - * /）= 基础工具（锤子、螺丝刀）
- 赋值运算符（= += -=）= 收纳工具（帮你整理东西）
- 比较运算符（> < ==）= 检测工具（判断大小、真假）
- 逻辑运算符（and or not）= 组合工具（多个条件一起判断）

AI应用开发中，判断接口状态、组合多个条件、累加统计数据，全靠这些运算符。

### ③ 语法说明

**赋值运算符**：
```python
# 基础赋值
x = 10

# 复合赋值运算符（简写）
x += 5    # x = x + 5，x现在是15
x -= 3    # x = x - 3，x现在是12
x *= 2    # x = x * 2，x现在是24
x /= 4    # x = x / 4，x现在是6.0
x //= 2   # x = x // 2，x现在是3.0
x %= 2    # x = x % 2，x现在是1.0
x **= 3   # x = x ** 3，x现在是1.0

# AI开发场景：累加API调用次数
api_calls = 0
api_calls += 1  # 每次调用API后+1
print(f"已调用{api_calls}次API")
```

**逻辑运算符 and/or/not**：
```python
# and：两个条件都满足才为True
age = 25
has_vip = True
if age >= 18 and has_vip:
    print("可以使用高级功能")

# or：满足一个条件就为True
is_admin = False
is_vip = True
if is_admin or is_vip:
    print("可以访问")

# not：取反
is_error = False
if not is_error:
    print("没有错误，继续执行")

# 组合使用
score = 85
is_passed = score >= 60
is_excellent = score >= 90

if is_passed and not is_excellent:
    print("及格但不是优秀")
```

**逻辑运算符的短路特性**：
```python
# and短路：前面为False，后面不执行
x = 0
if x != 0 and 10 / x > 2:  # x!=0为False，不会执行10/x
    print("条件满足")

# or短路：前面为True，后面不执行
name = "张三"
if name or "默认值":  # name为真，不会取"默认值"
    print(f"名字是：{name}")

# 实用技巧：用or设置默认值
user_input = ""
name = user_input or "匿名用户"
print(name)  # 输出：匿名用户
```

**运算符优先级**（从高到低）：
```python
# 1. 括号 () 最高
# 2. 幂运算 **
# 3. 正负号 +x, -x
# 4. 乘除 * / // %
# 5. 加减 + -
# 6. 比较 > < >= <= == !=
# 7. not
# 8. and
# 9. or 最低

# 示例
result = 2 + 3 * 4      # 14（先乘后加）
result = (2 + 3) * 4    # 20（括号优先）
result = 2 ** 3 ** 2    # 512（幂运算从右到左：2^(3^2)=2^9）

# 比较和逻辑组合
x = 10
result = x > 5 and x < 20  # True（先比较，再逻辑运算）
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `a = a + 1`写成`a == a + 1` | `=`赋值，`==`比较 | 赋值用单等号 |
| `and`和`or`优先级搞混 | `and`优先级高于`or` | 不确定就加括号 |
| 以为`or`返回True或False | `or`返回第一个为真的值 | `"" or "默认"`返回`"默认"` |
| 负数幂运算出错 | `-2**2`是`-(2**2)`=-4 | 负数幂加括号：`(-2)**2` |

### ⑤ 精简背诵笔记

```
【完整运算符体系】
✓ 赋值运算符：= += -= *= /= //= %= **=
✓ 逻辑运算符：and（与）、or（或）、not（非）
✓ 短路特性：and遇False停止，or遇True停止
✓ 优先级：() > ** > */% > +/- > 比较 > not > and > or
✓ or实用技巧：值 or 默认值（设置默认值）
✓ 不确定优先级就加括号
```

## 【补充】知识点 1.12：字符串完整体系

### ① 一句话通俗定义
**字符串完整体系 = 字符串的所有操作方式，包括索引、切片、各种处理方法。**

### ② 生活例子类比
字符串就像**一串珍珠项链**：
- 每颗珍珠 = 一个字符
- 项链的编号 = 索引（从0开始）
- 截取一段 = 切片
- 清洗、改造 = 字符串方法

AI应用开发中，文本清洗、关键词提取、prompt拼接，全靠字符串操作。

### ③ 语法说明

**字符串索引**：
```python
text = "Python"
# 正向索引（从0开始）
print(text[0])  # P
print(text[1])  # y
print(text[5])  # n

# 反向索引（从-1开始）
print(text[-1])  # n（最后一个）
print(text[-2])  # o（倒数第二个）
print(text[-6])  # P（第一个）
```

**字符串切片**：
```python
text = "Hello World"
# 基本切片 [start:end:step]
print(text[0:5])    # Hello（0到4，不包含5）
print(text[6:])     # World（从6到末尾）
print(text[:5])     # Hello（从头到4）
print(text[::2])    # HloWrd（每隔2个取一个）
print(text[::-1])   # dlroW olleH（反转字符串）

# AI开发场景：提取文本片段
prompt = "请帮我翻译：Hello World"
content = prompt[7:]  # 提取"翻译："后面的内容
print(content)  # Hello World
```

**字符串方法大全**：
```python
text = "  Hello World  "

# 去空格
print(text.strip())          # "Hello World"（去前后空格）
print(text.replace(" ",""))  # "HelloWorld"（去中间空格）replace(旧内容，新内容)
print(text.lstrip())         # "Hello World  "（只去左边）
print(text.rstrip())         # "  Hello World"（只去右边）

# 大小写转换
print("hello".upper())    # HELLO
print("WORLD".lower())    # world
print("hello world".title())  # Hello World（首字母大写）
print("Hello World".swapcase())  # hELLO wORLD（大小写互换）

# 查找与替换
text = "Python is great"
print(text.find("is"))       # 7（返回第一次出现的位置）
print(text.find("Java"))     # -1（找不到返回-1）
print(text.replace("Python", "AI"))  # AI is great
print(text.count("o"))       # 1（出现次数）

# 分割与拼接
text = "apple,banana,orange"
fruits = text.split(",")     # 按逗号分割
print(fruits)  # ['apple', 'banana', 'orange']

# join：把列表拼成字符串（join是split的逆操作）
words = ["I", "love", "Python"]
sentence = " ".join(words)
print(sentence)  # I love Python

# 判断类方法
print("123".isdigit())      # True（是否全是数字）
print("abc".isalpha())      # True（是否全是字母）
print("abc123".isalnum())   # True（是否字母或数字）
print("  ".isspace())       # True（是否全是空格）
print("Hello".startswith("He"))  # True（是否以某内容开头）
print("Hello".endswith("lo"))    # True（是否以某内容结尾）
```

**转义字符**：
```python
# \n 换行
print("第一行\n第二行")
# 输出：
# 第一行
# 第二行

# \t 制表符（Tab）
print("姓名\t年龄\t城市")
print("张三\t25\t北京")

# \' 和 \" 引号
print('他说："你好"')
print("It\'s a book")

# \\ 反斜杠本身
print("C:\\Users\\Admin")  # C:\Users\Admin

# 原始字符串 r""（不转义，路径常用）
print(r"C:\Users\Admin")   # 原样输出，不用双反斜杠
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `text[10]`报错索引越界 | 字符串没那么多字符 | 先用`len(text)`检查长度 |
| `find()`找不到返回-1 | 不是报错，是返回值 | 用`if text.find("x") != -1:`判断 |
| `split()`后忘记是列表 | 结果是列表，要用索引取 | `words[0]`取第一个元素 |
| `join()`参数搞错 | 是`分隔符.join(列表)` | `" ".join(words)`不是`words.join(" ")` |
| 路径反斜杠转义 | `\U` `\A`被当成转义 | 用原始字符串`r"C:\path"` |

## 【补充】知识点 1.13：报错基础理论

### ① 一句话通俗定义
**报错 = Python告诉你"代码哪里错了"的提示信息，学会看懂报错就能快速定位问题。**

### ② 生活例子类比
报错就像**老师的批改**：
- 红色批注 = 报错信息
- 批注位置 = 错误行号
- 批注内容 = 错误类型和原因
- 学会看批改，才能知道哪里需要改

AI应用开发中，代码出错是常态，能快速看懂报错、定位问题，是必备技能。

### ③ 语法说明

**三种高频报错类型**：

**1. SyntaxError（语法错误）**：
```python
# 错误示例1：中文符号
print("你好"）  # SyntaxError: invalid character in identifier

# 错误示例2：括号不匹配
print("你好"     # SyntaxError: unexpected EOF while parsing

# 错误示例3：引号不闭合
print("你好      # SyntaxError: EOL while scanning string literal

# 错误示例4：if语句没加冒号
if x > 5         # SyntaxError: expected ':'
    print("大")

# 如何看报错：
# SyntaxError: invalid syntax
# 上面这行表示"语法无效"，看箭头指向的位置
```

**2. TypeError（类型错误）**：
```python
# 错误示例1：字符串和数字相加
age = 25
print("年龄：" + age)  # TypeError: can only concatenate str (not "int") to str

# 修复：先转字符串
print("年龄：" + str(age))

# 错误示例2：函数参数类型不对
len(123)  # TypeError: object of type 'int' has no len()

# 修复：传字符串或列表
len("123")  # 3

# 错误示例3：列表索引用字符串
names = ["张三", "李四"]
print(names["0"])  # TypeError: list indices must be integers or slices, not str

# 修复：用数字索引
print(names[0])
```

**3. ValueError（值错误）**：
```python
# 错误示例1：字符串转整数，但内容不是数字
num = int("abc")  # ValueError: invalid literal for int() with base 10: 'abc'

# 修复：确保是纯数字
num = int("123")  # 123

# 错误示例2：字符串转数字，但包含小数点
num = int("12.5")  # ValueError: invalid literal for int()

# 修复：先用float转，再用int
num = int(float("12.5"))  # 12

# 错误示例3：列表remove不存在的元素
names = ["张三", "李四"]
names.remove("王五")  # ValueError: list.remove(x): x not in list

# 修复：先判断是否存在
if "王五" in names:
    names.remove("王五")
```

**如何看报错信息**：
```python
# 报错信息结构：
# File "文件名.py", 行号XX
#   出错的代码行
# 错误类型: 错误描述

```

## 【补充】知识点 1.14：浮点数精度

### ① 一句话通俗定义
**浮点数精度 = 小数在计算机里的存储方式导致的"不精确"问题。**

### ② 生活例子类比
浮点数精度就像**用尺子量东西**：
- 理论上1/3 = 0.333333...（无限循环）
- 但尺子只能量到0.33或0.333（有限精度）
- 计算机存小数也一样，只能存有限位数，所以会有误差

AI应用开发中，计算API调用费用、统计token数量，涉及金额时要特别注意精度。

### ③ 语法说明

**浮点数精度问题**：
```python
# 经典精度问题
print(0.1 + 0.2)        # 0.30000000000000004（不是0.3！）
print(0.1 + 0.2 == 0.3) # False（因为0.1+0.2不精确等于0.3）

# 为什么会这样？
# 计算机用二进制存小数，0.1在二进制里是无限循环小数
# 就像1/3在十进制里是0.3333...一样
# 计算机只能存有限位，所以有误差

# 比较小数是否相等（正确方式）
a = 0.1 + 0.2
b = 0.3
# ❌ 错误：直接比较
print(a == b)  # False

# ✅ 正确：用round()或math.isclose()
print(round(a, 10) == round(b, 10))  # True
import math
print(math.isclose(a, b))  # True

# AI开发场景：计算API调用费用
cost_per_call = 0.002  # 每次0.002元
calls = 100
total_cost = cost_per_call * calls
print(f"总费用：{total_cost}元")  # 0.2元
print(f"总费用：{round(total_cost, 4)}元")  # 0.2元（保留4位小数）
```

**高精度计算方案（decimal模块）**：
```python
from decimal import Decimal, getcontext

# 设置精度（小数位数）
getcontext().prec = 10

# 用Decimal存储小数（精确计算）
price = Decimal("0.1111111111111111111111")
quantity = Decimal("0.2")
total = price + quantity
print(total)  # 0.3（精确！）

# 注意：传入字符串，不是浮点数
# ❌ 错误
d = Decimal(0.1)  # 还是会不精确
# ✅ 正确
d = Decimal("0.1")  # 传字符串

# AI开发场景：精确计算API费用
cost_per_token = Decimal("0.00002")  # 每个token 0.00002元
tokens_used = Decimal("15000")
total_cost = cost_per_token * tokens_used
print(f"精确费用：{total_cost}元")  # 0.30000元
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `0.1 + 0.2`不等于`0.3` | 浮点数精度问题 | 用`round()`或`math.isclose()`比较 |
| 金额计算结果不对 | 浮点数不精确 | 用`Decimal`模块 |
| `Decimal(0.1)`还是不精确 | 传入了浮点数 | 传字符串：`Decimal("0.1")` |
| 以为所有小数都有精度问题 | 整数运算没问题 | 只有小数（float）有精度问题 |

### ⑤ 精简背诵笔记

```
【浮点数精度】
✓ 0.1 + 0.2 = 0.30000000000000004（不精确）
✓ 原因：计算机用二进制存小数，有限位数导致误差
✓ 比较小数：用round()或math.isclose()，不要直接==
✓ 精确计算：用decimal.Decimal，传字符串参数
✓ AI开发：涉及金额、费用计算，用Decimal
✓ 整数运算没有精度问题，只有小数有
```

## 【补充】知识点 1.15：编码基础

### ① 一句话通俗定义
**编码 = 计算机存储文字的规则，不同编码方式决定了文字怎么变成二进制存储。**

### ② 生活例子类比
编码就像**翻译密码本**：
- 中文"你" → 用UTF-8编码 → 变成二进制`01110000 10000101 10100100`
- 同一个字，用不同编码（UTF-8、GBK）→ 变成不同的二进制
- 解码时用错密码本 → 显示乱码

AI应用开发中，处理中文文本、读写文件、调用API，都要统一用UTF-8编码，否则乱码。

### ③ 语法说明

**常见编码方式**：
```python
# UTF-8：国际通用，支持所有语言（推荐）
# - 英文1字节，中文3字节
# - 网页、文件、API默认都用UTF-8

# GBK：中国国标，只支持中文
# - 英文1字节，中文2字节
# - Windows中文版默认编码（容易出问题）

# ASCII：最基础，只支持英文
# - 每个字符1字节
# - 不能存中文
```

**乱码产生原理**：
```python
# 场景：用UTF-8编码，用GBK解码
text = "你好"
# 编码：UTF-8
utf8_bytes = text.encode("utf-8")
print(utf8_bytes)  # b'\xe4\xbd\xa0\xe5\xa5\xbd'

# 错误解码：用GBK
try:
    wrong_text = utf8_bytes.decode("gbk")
    print(wrong_text)  # 显示乱码：浣犲ソ
except:
    print("解码错误")

# 正确解码：用UTF-8
correct_text = utf8_bytes.decode("utf-8")
print(correct_text)  # 你好
```

**Python中编码应用**：
```python
# 1. 文件读写时指定编码
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("你好世界")

with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

# 2. 字符串和字节转换
text = "Python"
# 字符串 → 字节（编码）
bytes_data = text.encode("utf-8")
print(bytes_data)  # b'Python'

# 字节 → 字符串（解码）
decoded_text = bytes_data.decode("utf-8")
print(decoded_text)  # Python

# 3. 中文转换
text = "你好"
bytes_data = text.encode("utf-8")
print(bytes_data)  # b'\xe4\xbd\xa0\xe5\xa5\xbd'
decoded = bytes_data.decode("utf-8")
print(decoded)  # 你好
```

**Windows系统编码问题**：
```python
# Windows默认编码是GBK，Python默认是UTF-8
# 读写文件时必须指定encoding="utf-8"

# ❌ 错误（Windows可能乱码）
with open("test.txt", "w") as f:
    f.write("你好")

# ✅ 正确（明确指定UTF-8）
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("你好")

# 读取其他编码的文件
with open("gbk_file.txt", "r", encoding="gbk") as f:
    content = f.read()
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| 文件读取中文乱码 | 没指定encoding或编码不对 | 加`encoding="utf-8"` |
| Windows下写文件乱码 | 系统默认GBK，Python用UTF-8 | 始终指定`encoding="utf-8"` |
| `UnicodeDecodeError` | 用错编码解码 | 确认文件编码，用对应编码解码 |
| 网页爬取中文乱码 | 网页编码和解码编码不一致 | 先看网页编码（通常UTF-8），再用对应编码解码 |

### ⑤ 精简背诵笔记

```
【编码基础】
✓ UTF-8：国际通用，支持所有语言，推荐用
✓ GBK：中国国标，Windows默认（容易出问题）
✓ ASCII：只支持英文
✓ 乱码原因：编码和解码用的规则不一致
✓ 文件读写：必须加encoding="utf-8"
✓ 字符串转字节：encode("utf-8")
✓ 字节转字符串：decode("utf-8")
✓ AI开发：所有文本处理统一用UTF-8
```
