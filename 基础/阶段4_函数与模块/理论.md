## 知识点 4.1：函数基础

### ① 一句话通俗定义
**函数 = 把一段代码打包成一个"工具"，起个名字，以后随时调用。**

### ② 生活例子类比
函数就像**微波炉的"热饭"按钮**：
- 你不需要每次都重新接线、调功率（不用重复写代码）
- 只需要按"热饭"按钮（调用函数）
- 放进去的是冷饭（参数），出来的是热饭（返回值）

AI应用开发中，"调用AI接口"这个动作会反复用，把它写成函数，每次只需一行代码就能调用。

### ③ 语法说明

```python
# ① 定义函数：用def声明，后面跟函数名和参数（参数=输入材料）
def greet(name):  # name是参数，调用时传入具体值
    """打招呼的函数"""  # 文档字符串（函数说明）
    message = "你好，" + name + "！"  # 函数内部逻辑
    return message  # 返回结果（打包好的成品）

# ② 调用函数：函数名+括号，传入参数值
result = greet("张三")  # 把"张三"传给name，得到返回值赋给result
print(result)  # 你好，张三！

# ③ 多个参数：可以接收多个输入
def add(a, b):  # a和b是两个参数
    return a + b  # 返回a+b的结果

print(add(3, 5))  # 8（3给a，5给b，3+5=8）

# ④ 默认参数：参数有默认值，调用时可以省略
def greet2(name, greeting="你好"):  # greeting默认值是"你好"
    return greeting + "，" + name + "！"

print(greet2("张三"))          # 你好，张三！（没给greeting，用默认值）
print(greet2("张三", "早上好"))  # 早上好，张三！（给了greeting，用新值）

# ⑤ 没有return的函数：只做事，不返回值（返回None）
def say_hello(name):
    print("你好，" + name + "！")  # 直接打印，没有return

say_hello("李四")  # 直接打印，没有返回值
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `NameError: name 'xxx' is not defined` | 函数还没定义就调用了，或函数名拼写错误 | 确保def在调用之前，检查拼写 |
| 函数里改了参数，外面没变 | 函数内部的变量是"副本"，不影响外面 | 用return把结果传出来 |
| 忘记写return | 函数没有return，调用后得到None | 需要结果就加return |
| 参数个数不对 | 调用时给的参数和定义时不一样多 | 检查参数数量，或用默认参数 |

### ⑤ 精简背诵笔记

```
【函数基础】
✓ 定义：def 函数名(参数):
✓ 调用：函数名(参数)
✓ 返回值：return 值（没有return就返回None）
✓ 默认参数：def func(a, b=10)
✓ 函数必须先定义再调用
✓ 函数内部的变量不影响外部
```

## 知识点 4.2：函数进阶

### ① 一句话通俗定义
**函数进阶 = 让函数更灵活：可以接收任意数量的参数、可以把函数当参数传递。**

### ② 语法说明

```python
# *args：接收任意数量的位置参数（打包成元组，像装行李一样）
# *表示"打包"，把所有位置参数打包成一个元组args
def sum_all(*args):
    total = 0
    for num in args:  # 遍历元组里的每一个数
        total += num  # 累加
    return total

print(sum_all(1, 2, 3))       # 6（args=(1,2,3)）
print(sum_all(1, 2, 3, 4, 5)) # 15（args=(1,2,3,4,5)）

# **kwargs：接收任意数量的关键字参数（打包成字典）
# **表示"打包成字典"，key=value格式的参数都被打包进kwargs
def print_info(**kwargs):
    for key, value in kwargs.items():  # 遍历字典的键值对
        print(key + ": " + str(value))

print_info(name="张三", age=25, city="北京")  # kwargs={"name":"张三", "age":25, "city":"北京"}

# lambda：一行小函数（适合简单操作，像写便利贴一样）
# 格式：lambda 参数: 返回值表达式（自动返回结果，不用写return）
square = lambda x: x ** 2  # x是参数，x**2是计算逻辑（返回x的平方）
print(square(5))  # 25（调用时传入5，5**2=25）

# lambda配合排序使用（最常用场景）
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 92},
    {"name": "王五", "score": 78},
]
# key=lambda s: s["score"]：告诉排序算法，按每个字典的"score"字段来比较
# reverse=True：从高到低排序（默认False是从低到高）
students.sort(key=lambda s: s["score"], reverse=True)
for s in students:
    print("  " + s["name"] + ": " + str(s["score"]) + "分")
```

### ③ 精简背诵笔记

```
【函数进阶】
✓ *args：接收任意多个位置参数 → 元组
✓ **kwargs：接收任意多个关键字参数 → 字典
✓ lambda：一行小函数，lambda 参数: 表达式
✓ lambda常用于排序、过滤等简单场景
```

## 知识点 4.3：模块 import

###  一句话通俗定义
**模块 = 别人写好的"工具包"，用import导入后就能直接使用里面的功能。**

### ② 生活例子类比
模块就像**工具箱**：
- Python自带一些工具箱（如math数学工具、random随机工具）
- 别人也做了很多工具箱（如requests网络工具）
- 你用import把工具箱拿过来，就能用里面的工具

AI应用开发中，调用AI接口用的`openai`、`dashscope`都是模块。不会import，就没法用任何现成工具。

### ③ 语法说明

```python
# 方式1：导入整个模块（像搬整个工具箱过来）
import math
print(math.sqrt(16))  # 4.0（开平方，要写math.前缀）
print(math.pi)        # 3.14159...

# 方式2：只导入需要的功能（只拿你要用的工具）
from math import sqrt, pi
print(sqrt(16))  # 4.0（不用写math.了，直接用）
print(pi)        # 3.14159...

# 方式3：给模块起别名（工具箱太重，给它起个简称）
import math as m
print(m.sqrt(16))  # 用m代替math，更简洁

# 方式4：导入所有（把工具箱里的东西全倒出来，不推荐！容易和自己的变量重名）
from math import *
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `ModuleNotFoundError: No module named 'xxx'` | 这个模块没安装 | 用`pip install xxx`安装 |
| 导入后调用时还要加模块名 | 用`import xxx`导入的，调用要加`xxx.` | 用`from xxx import yyy`就不用加前缀 |
| 自己写的文件和模块同名 | 如文件名叫`math.py`，会覆盖系统模块 | 不要用系统模块名做文件名 |

### ⑤ 精简背诵笔记

```
【模块 import】
✓ import 模块名 → 调用时：模块名.功能()
✓ from 模块名 import 功能 → 直接调用功能()
✓ import 模块名 as 别名 → 用别名代替
✓ 第三方模块要先安装：pip install 模块名
✓ 文件名不要和系统模块同名
```

## 知识点 4.4：常用内置模块

### ① 一句话通俗定义
**Python自带了很多实用模块，不用安装就能用，覆盖数学、随机、时间、路径等常见需求。**

### ② 常用模块速查

```python
# --- math：数学计算模块 ---
import math
print(math.sqrt(16))    # 4.0 开平方（计算平方根）
print(math.ceil(3.2))   # 4 向上取整（3.2→4，天花板方向）
print(math.floor(3.8))  # 3 向下取整（3.8→3，地板方向）

# --- random：随机数模块（抽奖、随机选择等）---
import random
print(random.randint(1, 10))   # 1到10的随机整数（包含1和10）
print(random.choice(["a", "b", "c"]))  # 从列表中随机选一个
random.shuffle([1, 2, 3])      # 打乱列表顺序（原地修改）

# --- datetime：日期时间模块 ---
from datetime import datetime
now = datetime.now()  # 获取当前时间
print(now)                    # 2026-07-18 14:30:00（完整时间）
print(now.strftime("%Y-%m-%d"))  # 2026-07-18（按格式输出，%Y年-%m月-%d日）

# --- os：文件和路径操作模块 ---
import os
print(os.getcwd())            # 当前目录（获取当前工作路径）
print(os.path.exists("test.txt"))  # 文件是否存在（判断文件/文件夹是否存在）
print(os.path.join("folder", "file.txt"))  # 拼接路径（自动处理不同系统的路径分隔符）

# --- json：处理JSON数据（AI接口必备）---
import json
# JSON = 电脑之间传数据的标准格式，像快递单一样通用
# AI接口的请求和响应都是JSON格式，必须会用

# ① dumps：把Python字典打包成JSON字符串（准备发快递）
data = {"name": "张三", "score": 90}
# ensure_ascii=False：中文保持原样，不变成\u5f20\u4e09这种编码
json_str = json.dumps(data, ensure_ascii=False)
print(json_str)  # {"name": "张三", "score": 90}

# ② loads：把收到的JSON字符串拆开变成Python字典（拆快递）
parsed = json.loads(json_str)
print(parsed["name"])  # 张三
```

### ③ 精简背诵笔记

```
【常用内置模块】
✓ math：sqrt()开方, ceil()向上取整, floor()向下取整
✓ random：randint()随机整数, choice()随机选, shuffle()打乱
✓ datetime：now()当前时间, strftime()格式化
✓ os：getcwd()当前目录, path.exists()判断存在, path.join()拼接路径
✓ json：dumps()字典转JSON, loads()JSON转字典（AI接口必备！）
```

## 【补充】知识点 4.5：局部变量与全局变量作用域

### ① 一句话通俗定义
**局部变量 = 函数内部创建的变量，只在函数内有效；全局变量 = 函数外部创建的变量，整个文件都能用。**

### ② 生活例子类比
- **局部变量**：你在自己房间里的东西 → 只有你能用，别人进不来拿
- **全局变量**：客厅里的东西 → 所有人都能用

AI应用开发中，理解作用域能避免"变量找不到"或"意外覆盖全局变量"的bug。

### ③ 语法说明

**局部变量**：函数内部创建的变量，只在函数内有效（出了函数就找不到了）
```python
def calculate():
    result = 100  # 局部变量，只在calculate函数内有效
    print(result)  # ✅ 函数内可以访问

calculate()  # 100
# print(result)  # ❌ 报错！函数外部访问不到局部变量（NameError）
```

**全局变量**：函数外部创建的变量，整个文件都能用
```python
api_key = "sk-xxx123"  # 全局变量（定义在所有函数外面）

def call_api():
    print(api_key)  # ✅ 函数内可以读取全局变量

call_api()  # sk-xxx123（函数内读取成功）
print(api_key)  # ✅ 函数外部也能访问
```

**函数内修改全局变量的坑**：
```python
count = 0  # 全局变量

def increment_wrong():
    count = count + 1  # ❌ 报错！Python以为你要创建新的局部变量count
                       # 但count还没赋值就用了，所以报错UnboundLocalError

def increment_right():
    global count  # 声明：我要使用全局的count变量，不是新创建的
    count = count + 1  # ✅ 修改全局变量

# increment_wrong()  # UnboundLocalError（会报错）
increment_right()  # 正确修改全局变量
print(count)  # 1（全局变量被成功修改）
```

**AI开发场景：配置信息用全局变量**：
```python
# 全局配置（定义在外面，所有函数都能用）
API_URL = "https://api.example.com"  # AI接口地址
MAX_RETRY = 3  # 最大重试次数
TIMEOUT = 30  # 超时时间（秒）

def call_ai_api(prompt):
    """调用AI接口"""
    print(f"请求地址：{API_URL}")  # 读取全局配置
    print(f"最大重试：{MAX_RETRY}次")  # 读取全局配置
    return f"AI回答：{prompt}"

result = call_ai_api("你好")
print(result)  # AI回答：你好
```

**作用域查找顺序（LEGB规则）**：从内向外找变量
```python
x = "全局"  # Global（全局）

def outer():
    x = "外层"  # Enclosing（外层函数）
    
    def inner():
        x = "内层"  # Local（局部）
        print(x)  # 先找局部，找到"内层"
    
    inner()  # 调用内层函数
    print(x)  # 找外层，找到"外层"

outer()  # 调用外层函数
print(x)  # 找全局，找到"全局"

# 输出：
# 内层
# 外层
# 全局
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `UnboundLocalError` | 函数内修改全局变量没加`global` | 加`global 变量名`声明 |
| 函数外访问不到函数内变量 | 局部变量作用域仅限函数内 | 用`return`返回值 |
| 全局变量被意外修改 | 函数内直接修改了全局变量 | 尽量避免，或用`global`明确声明 |
| 嵌套函数变量混乱 | 没理解LEGB查找顺序 | 每层函数独立变量名 |

### ⑤ 精简背诵笔记

```
【变量作用域】
✓ 局部变量：函数内创建，函数外访问不到
✓ 全局变量：函数外创建，整个文件都能用
✓ 函数内读取全局变量：可以直接读
✓ 函数内修改全局变量：必须加global声明
✓ LEGB顺序：Local → Enclosing → Global → Built-in
✓ AI开发：配置信息用全局变量，函数内尽量用局部变量
```

## 【补充】知识点 4.6：函数无return默认返回None

### ① 一句话通俗定义
**函数没有return语句，或return后面没值，默认返回None（空值）。**

### ② 生活例子类比
函数就像**快递柜**：
- 有return → 快递柜里有东西，你取出来
- 没return → 快递柜是空的，你取出来的是"空"（None）

AI应用开发中，忘记写return是新手最常见的bug之一，导致"函数调用后得到None"。

### ③ 语法说明

**没有return的函数**：函数只做事不返回结果，默认返回None（空值）
```python
def say_hello(name):
    print(f"你好，{name}！")  # 只打印，没有return

result = say_hello("张三")  # 调用函数，但没有返回值
print(result)  # None（函数没有return，默认返回None）
```

**return后面没值**：部分分支没有return，走到那里就返回None
```python
def check_age(age):
    if age >= 18:
        return "成年"  # ✅ age>=18时返回"成年"
    # else分支没有return，age<18时走到这里就返回None

result = check_age(15)  # 15<18，没有return
print(result)  # None（不是预期的"未成年"！）
```

**return None的显式写法**：找不到结果时显式返回None，代码更清晰
```python
def find_user(user_id):
    """查找用户，找不到返回None"""
    users = {"001": "张三", "002": "李四"}
    if user_id in users:
        return users[user_id]  # 找到就返回用户名
    return None  # 没找到就显式返回None（推荐写法）

result = find_user("003")
if result is None:  # 判断是否为None（用is，不用==）
    print("用户不存在")
else:
    print(f"找到用户：{result}")
```

**AI开发场景：接口调用函数**：成功返回结果，失败返回None
```python
def call_ai_api(prompt, api_key):
    """
    调用AI接口
    成功返回回答文本，失败返回None
    """
    # 参数校验：没有API Key就返回None
    if not api_key:
        print("错误：缺少API Key")
        return None  # ❌ 失败返回None
    
    # 参数校验：提问为空就返回None
    if not prompt:
        print("错误：提问为空")
        return None  # ❌ 失败返回None
    
    # ✅ 校验通过，模拟成功返回
    return f"AI回答：{prompt}"

# 使用函数：先判断是否成功
response = call_ai_api("你好", "sk-xxx")
if response is None:  # 判断是否失败
    print("调用失败，请检查参数")
else:
    print(response)  # 打印成功结果
```

**常见错误：忘记return**：最容易踩的坑！
```python
# ❌ 错误：忘记return，result永远是None
def calculate_sum(a, b):
    result = a + b  # 计算了结果，但没返回！
    # 忘记写return

total = calculate_sum(3, 5)
print(total)  # None（不是8！）

# ✅ 正确：加上return，把结果传出来
def calculate_sum(a, b):
    result = a + b
    return result  # 返回结果

total = calculate_sum(3, 5)
print(total)  # 8（正确！）
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| 函数调用后得到None | 忘记写return | 检查函数是否有return语句 |
| 某些情况返回None | if分支没写return | 所有分支都要有return |
| 以为print就是return | print只是打印，不返回 | 用return返回值 |
| return后代码不执行 | return会立即结束函数 | return放在最后 |

### ⑤ 精简背诵笔记

```
【函数返回值】
✓ 没有return → 返回None
✓ return后面没值 → 返回None
✓ return会立即结束函数
✓ 所有if分支都要有return
✓ print是打印，return是返回（不一样！）
✓ AI开发：接口调用函数失败时返回None
✓ 判断None用 is None，不要用 == None


## 【补充】知识点 4.7：函数文档字符串标准写法

### ① 一句话通俗定义
**文档字符串 = 函数开头的说明文字，告诉别人"这个函数是干嘛的、参数是什么、返回什么"。**

### ② 生活例子类比
文档字符串就像**产品说明书**：
- 产品名称 = 函数名
- 功能说明 = 函数作用
- 参数说明 = 需要给什么
- 返回值说明 = 会得到什么

AI应用开发中，封装AI接口函数时写好文档字符串，团队协作时别人一看就懂。

### ③ 语法说明

**标准文档字符串格式**：用"""包起来，放在函数第一行
```python
def call_ai_api(prompt, model="gpt-3.5", max_tokens=1000):
    """
    调用AI接口获取回答              # 第一行：功能简要说明
    
    参数：                         # 参数说明（每行一个参数）
        prompt (str): 用户提问内容       # 参数名（类型）: 说明
        model (str): 使用的模型，默认gpt-3.5
        max_tokens (int): 最大token数，默认1000
    
    返回：                         # 返回值说明
        str: AI的回答文本              # 返回类型: 说明
        None: 调用失败时返回None
    
    示例：                         # 使用示例（可选但推荐）
        >>> response = call_ai_api("你好")
        >>> print(response)
        'AI回答：你好！'
    """
    # 函数实现...
    return f"AI回答：{prompt}"

# 查看文档字符串（两种方式）
print(call_ai_api.__doc__)  # 方式1：打印__doc__属性
# 或用help()
help(call_ai_api)  # 方式2：用help()函数（更友好）
```

**简化版文档字符串**：简单函数可以只写一行说明

def clean_text(text):

    return text.strip().lower()

def calculate_cost(tokens, price_per_token):

**AI开发场景：封装API函数**：文档字符串非常重要
```python
def send_request(url, method="GET", data=None, timeout=30):
    """
    发送HTTP请求（AI开发中用来调用接口）
    
    参数：
        url (str): 请求地址（如"https://api.example.com"）
        method (str): 请求方法，GET或POST（默认GET）
        data (dict): POST请求的数据（字典格式，会转成JSON）
        timeout (int): 超时时间（秒，默认30）
    
    返回：
        dict: 响应数据，格式为{"status": 200, "data": {...}}
        None: 请求失败时返回None
    
    异常：
        TimeoutError: 请求超时（超过timeout秒没响应）
        ConnectionError: 连接失败（网络问题）
    """
    # 模拟实现
    return {"status": 200, "data": data}

def process_ai_response(response):
    """
    处理AI接口返回的响应（提取回答文本）
    
    参数：
        response (dict): API返回的原始响应（用json.loads解析后的字典）
    
    返回：
        str: 提取的回答文本（成功时）
        None: 响应无效时返回None
    """
    if response is None:
        return None  # 响应为空
    
    if response.get("status") != 200:
        return None  # 状态码不是200（失败）
    
    # 从嵌套字典中提取回答
    return response.get("data", {}).get("answer")
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| 文档字符串位置不对 | 必须紧跟def下一行 | 放在函数开头第一行 |
| 文档字符串格式混乱 | 没有统一格式 | 用标准格式：参数、返回、示例 |
| 忘记写文档字符串 | 觉得麻烦 | 养成习惯，每个函数都写 |
| 文档字符串和实际不符 | 代码改了文档没改 | 同步更新文档 |

### ⑤ 精简背诵笔记

```
【函数文档字符串】
✓ 位置：函数开头第一行（用"""包起来）
✓ 内容：功能说明 + 参数说明 + 返回值说明
✓ 参数格式：参数名 (类型): 说明
✓ 返回格式：返回类型: 说明
✓ 查看文档：函数名.__doc__ 或 help(函数名)

## 【补充】知识点 4.8：json模块详解

### ① 一句话通俗定义
**json模块 = Python处理JSON数据的工具，用于字典和JSON字符串之间的转换。**

### ② 生活例子类比
JSON就像**国际通用语言**：
- 你说中文（Python字典）
- 外国人说英文（JSON字符串）
- json模块 = 翻译官，帮你互相翻译

AI应用开发中，大模型接口返回的数据基本都是JSON格式，必须会用json模块解析。

### ③ 语法说明

**json.dumps()：字典 → JSON字符串（打包成快递单）**
```python
import json

# Python字典（你自己的数据结构）
data = {
    "name": "张三",
    "age": 25,
    "city": "北京"
}

# 转成JSON字符串（准备发送给AI接口）
json_str = json.dumps(data, ensure_ascii=False)
# ensure_ascii=False：中文保持原样，不变成\u5f20\u4e09这种看不懂的编码
print(json_str)
# {"name": "张三", "age": 25, "city": "北京"}

# indent参数：美化输出（缩进2个空格，方便人看）
json_str_pretty = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str_pretty)
# {
#   "name": "张三",
#   "age": 25,
#   "city": "北京"
# }
```

**json.loads()：JSON字符串 → 字典（拆快递）**
```python
import json

# JSON字符串（通常来自AI接口返回）
json_str = '{"name": "张三", "age": 25, "city": "北京"}'
# 注意：JSON必须用双引号！不能用单引号！

# 转成Python字典（方便程序处理）
data = json.loads(json_str)
print(data)  # {'name': '张三', 'age': 25, 'city': '北京'}
print(data["name"])  # 张三（用字典方式访问）
```

**AI开发场景：解析大模型返回数据**
```python
import json

# 模拟AI接口返回的JSON字符串（真实场景中是从网络收到的）
api_response = """
{
    "status": "success",
    "data": {
        "answer": "Python是一门优秀的编程语言",
        "tokens_used": 150,
        "model": "gpt-3.5"
    },
    "usage": {
        "prompt_tokens": 10,
        "completion_tokens": 150,
        "total_tokens": 160
    }
}
"""

# 解析JSON字符串 → 字典
response_dict = json.loads(api_response)

# 提取数据（从嵌套字典中取）
if response_dict["status"] == "success":  # 先判断是否成功
    answer = response_dict["data"]["answer"]  # 取data里的answer
    tokens = response_dict["usage"]["total_tokens"]  # 取usage里的total_tokens
    print(f"AI回答：{answer}")
    print(f"消耗token：{tokens}")
else:
    print("调用失败")
```

**json.dump()和json.load()：文件操作（保存/读取JSON文件）**

> 📌 **知识点预览**：`with open` 是阶段5"文件操作"的核心内容，这里提前用最简单的方式演示。
> 完整的文件操作知识（模式选择、路径处理、异常处理等）请在阶段5详细学习。

```python
import json

# ① 读取现有数据（load带一个p，读文件）
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
    # data = {'name': '张三', 'age': 25}
    print("读取成功:", data)

# ② 在内存中操作数据（修改/新增字段）
data["age"] = 26           # 修改：年龄从25改为26
data["city"] = "北京"      # 新增：添加城市字段
print("修改后:", data)

# ③ 保存回文件（dump带一个p，写文件）
# "w"=write写入模式（覆盖原内容），encoding="utf-8"支持中文
# ensure_ascii=False：允许中文正常保存
# indent=2：缩进2空格，格式化输出，方便阅读
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
    print("保存成功！")
```

**处理JSON数组（JSON中的[]对应Python的列表）**
```python
import json

# JSON数组（用[]表示，对应Python的列表）
json_array = '[{"name": "张三"}, {"name": "李四"}]'
data_list = json.loads(json_array)  # 解析后是列表
print(data_list)  # [{'name': '张三'}, {'name': '李四'}]

# 遍历列表
for item in data_list:
    print(item["name"])  # 张三、李四
```

**处理嵌套JSON（复杂数据结构）**
```python
import json

# 复杂JSON：包含字典和数组的嵌套
complex_json = """
{
    "users": [  # users是一个数组（列表）
        {"id": 1, "name": "张三", "skills": ["Python", "AI"]},  # 每个用户有skills数组
        {"id": 2, "name": "李四", "skills": ["Java", "Web"]}
    ],
    "total": 2  # 总用户数
}
"""

# 解析
data = json.loads(complex_json)

# 遍历users数组
for user in data["users"]:
    print(f"用户：{user['name']}")
    # skills是列表，用join转成字符串
    print(f"  技能：{', '.join(user['skills'])}")
```

### ④ 新手高频踩坑清单

| 错误现象 | 产生原因 | 修复方法 |
|---------|---------|---------|
| `json.loads()`报错 | JSON字符串格式不对（如单引号） | JSON必须用双引号 |
| 中文显示Unicode | 没加`ensure_ascii=False` | dumps时加`ensure_ascii=False` |
| `json.load()`和`json.loads()`搞混 | load读文件，loads读字符串 | load文件，loads字符串 |
| 解析后取不到值 | 键名写错或层级不对 | 先print看结构 |

### ⑤ 精简背诵笔记

```
【json模块详解】
✓ dumps(字典)：字典 → JSON字符串
✓ loads(字符串)：JSON字符串 → 字典
✓ dump(字典, 文件)：字典 → JSON文件
✓ load(文件)：JSON文件 → 字典
✓ ensure_ascii=False：中文正常显示
✓ indent=2：美化输出（缩进）
✓ AI开发：解析大模型返回的JSON数据
✓ JSON格式要求：双引号、不能单引号
```
