## 知识点 6.1：什么是正则表达式

### ① 一句话通俗定义
**正则表达式 = 一种用特殊符号写的"文本搜索模式"。**

就像你在一本书里找特定的句子，不用逐字读，而是告诉搜索引擎"帮我找所有以'AI'开头的词"。

### ② 生活例子类比
正则表达式就像**超市货架上的价格标签扫描仪**：
- 你设定一个规则："找所有价格在10-50元之间的商品"
- 扫描仪扫过所有商品，自动找出符合条件的
- 正则就是这个"规则"，文本就是"货架"

### ③ AI开发场景
| 场景 | 正则能做什么 |
|------|-------------|
| 用户输入清洗 | 去掉多余空格、表情、特殊符号 |
| 提取关键信息 | 从对话中提取邮箱、手机号、URL |
| 敏感内容过滤 | 识别并替换违规词汇 |
| 解析模型输出 | 从大段文本中提取结构化数据 |

## 知识点 6.2：re模块基础——match、search、findall

### ① 一句话通俗定义
**re模块 = Python自带的正则表达式工具箱。**

### ② 核心函数对比

| 函数 | 作用 | 返回值 | 示例 |
|------|------|--------|------|
| `re.match()` | **从开头**匹配 | 匹配对象或None | `re.match(r"hello", "hello world")` → 匹配成功 |
| `re.search()` | **在任意位置**查找第一个匹配 | 匹配对象或None | `re.search(r"world", "hello world")` → 匹配成功 |
| `re.findall()` | **找出所有**匹配项 | 列表 | `re.findall(r"\d+", "价格：99元，数量：10")` → `["99", "10"]` |

### ③ 语法说明

```python
import re

# ① match：只从字符串开头匹配
text = "hello world"
result = re.match(r"hello", text)
if result:
    print(f"匹配成功：{result.group()}")  # hello
else:
    print("匹配失败")

# ② search：在整个字符串中找第一个匹配
result = re.search(r"world", text)
if result:
    print(f"找到：{result.group()}")  # world

# ③ findall：找出所有匹配
text = "张三：13800138000，李四：13900139000"
phones = re.findall(r"\d{11}", text)
print(phones)  # ['13800138000', '13900139000']
```

## 知识点 6.3：正则语法——字符类、量词、分组

### ① 常用字符类

| 符号 | 含义 | 例子 |
|------|------|------|
| `.` | 任意单个字符（除换行符） | `a.c` 匹配 `abc`、`a1c` |
| `\d` | 任意数字 | `\d+` 匹配 `123`、`0` |
| `\w` | 字母、数字、下划线 | `\w+` 匹配 `hello`、`user_1` |
| `\s` | 空白字符（空格、换行等） | `a\sb` 匹配 `a b` |
| `[abc]` | 字符集合，匹配a或b或c | `[aeiou]` 匹配任意元音字母 |
| `[^abc]` | 否定字符集合，不匹配a/b/c | `[^0-9]` 匹配非数字 |
| `[a-z]` | 字符范围，匹配a到z | `[A-Za-z]` 匹配字母 |

### ② 常用量词

| 符号 | 含义 | 例子 |
|------|------|------|
| `*` | 0次或多次 | `ab*c` 匹配 `ac`、`abc`、`abbc` |
| `+` | 1次或多次 | `ab+c` 匹配 `abc`、`abbc`，不匹配 `ac` |
| `?` | 0次或1次 | `colou?r` 匹配 `color`、`colour` |
| `{n}` | 恰好n次 | `\d{4}` 匹配 `1234` |
| `{n,m}` | n到m次 | `\d{2,4}` 匹配 `12`、`123`、`1234` |
| `{n,}` | 至少n次 | `\d{2,}` 匹配 `12`、`12345` |

### ③ 分组——用()提取子内容

```python
import re

# 提取日期中的年、月、日
text = "日期：2024-07-15"
pattern = r"(\d{4})-(\d{2})-(\d{2})"
result = re.search(pattern, text)

if result:
    year = result.group(1)   # 第1个分组：2024
    month = result.group(2)  # 第2个分组：07
    day = result.group(3)    # 第3个分组：15
    print(f"年份：{year}，月份：{month}，日期：{day}")
```

## 知识点 6.4：贪婪匹配与非贪婪匹配

### ① 一句话通俗定义
**贪婪匹配 = 尽可能多吃；非贪婪匹配 = 吃到刚好满足。**

### ② 对比示例

```python
import re

text = "<html><head>标题</head></html>"

# 贪婪匹配（默认）：会匹配最长的内容
greedy = re.search(r"<.*>", text)
print(greedy.group())  # <html><head>标题</head></html>

# 非贪婪匹配（加?）：匹配最短的内容
non_greedy = re.search(r"<.*?>", text)
print(non_greedy.group())  # <html>
```

**总结**：量词后面加 `?` 就变成非贪婪模式。

## 知识点 6.5：re.compile预编译正则表达式

### ① 一句话通俗定义
**re.compile() = 把正则表达式"编译"成一个可重复使用的模板。**

就像提前把印章刻好，以后每次盖章都很快，不用每次都重新刻。

### ② 语法说明

```python
import re

# ① 预编译正则（只做一次）
pattern = re.compile(r"\d{11}")  # 匹配手机号的模板

# ② 多次使用（效率更高）
text1 = "我的手机号是13800138000"
text2 = "联系电话：13900139000"

phone1 = pattern.search(text1)
phone2 = pattern.search(text2)

print(phone1.group())  # 13800138000
print(phone2.group())  # 13900139000
```

**什么时候用**：同一个正则表达式需要匹配多次时，用compile可以提高效率。

## 知识点 6.6：AI开发实战——清洗和提取

### 场景1：清洗用户输入

```python
import re

user_input = "  你好啊！！！ 我想咨询一下 AI 相关的问题...\n\n"

# 去掉首尾空白
cleaned = user_input.strip()
# 去掉多余标点
cleaned = re.sub(r"[！。？、]{2,}", "。", cleaned)
# 去掉多余空格
cleaned = re.sub(r"\s+", " ", cleaned)

print(cleaned)  # 你好啊。我想咨询一下 AI 相关的问题。
```

### 场景2：提取邮箱和URL

```python
import re

text = """
联系我们：
邮箱：support@example.com
备用邮箱：hello@test.org
官网：https://www.example.com/path?query=1
文档：http://docs.test.com
"""

# 提取邮箱
emails = re.findall(r"[\w.-]+@[\w.-]+\.\w+", text)
print("邮箱：", emails)

# 提取URL
urls = re.findall(r"https?://[\w.-]+(/[\w./?%&=-]*)?", text)
print("URL：", urls)
```

### 场景3：解析大模型返回的结构化数据

```python
import re

# 大模型返回的文本
model_response = """
分析结果：
- 情感倾向：正面
- 置信度：0.92
- 关键词：["人工智能", "深度学习", "应用"]
"""

# 提取情感倾向
sentiment = re.search(r"情感倾向：(\S+)", model_response).group(1)
# 提取置信度
confidence = float(re.search(r"置信度：(\d+\.?\d*)", model_response).group(1))

print(f"情感：{sentiment}，置信度：{confidence}")
```
