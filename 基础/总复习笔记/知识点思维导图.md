## Python基础语法（AI应用开发定制版）

```
Python基础
│
├── 阶段1：Python初相识
│   ├── print() 打印输出
│   │   ├── print(内容)
│   │   ├── 文字加引号，数字不加
│   │   ├── 多内容用逗号隔开
│   │   └── 换行符 \n
│   │
│   ├── 注释
│   │   ├── 单行：# 内容
│   │   └── 多行：""" 内容 """
│   │
│   ├── 变量
│   │   ├── 变量名 = 值
│   │   ├── 命名：小写+下划线
│   │   ├── 不能用保留字
│   │   └── 可重新赋值
│   │
│   ├── 四大数据类型
│   │   ├── int 整数
│   │   ├── float 小数
│   │   ├── str 字符串（带引号）
│   │   └── bool 布尔值（True/False）
│   │
│   ├── input() 输入
│   │   ├── 返回值永远是str
│   │   └── 做运算需先转类型
│   │
│   ├── 类型转换
│   │   ├── int() / float() / str() / bool()
│   │   ├── int()砍尾不四舍五入
│   │   └── round() 四舍五入
│   │
│   └── 基础运算符
│       ├── 算术：+ - * / // % **
│       ├── 字符串：+ 拼接，* 重复
│       └── 比较：> < >= <= == !=
│
├── 阶段2：条件判断与循环
│   ├── if条件判断
│   │   ├── if / elif / else
│   │   ├── 后面必须加冒号 :
│   │   ├── 下一行必须缩进
│   │   └── 判断相等用 ==
│   │
│   ├── for循环
│   │   ├── for i in range(n)
│   │   ├── range(a,b) 不包含b
│   │   ├── 可遍历列表、字符串
│   │   └── 循环体必须缩进
│   │
│   ├── while循环
│   │   ├── while 条件:
│   │   ├── 循环体内更新条件变量
│   │   ├── break 跳出循环
│   │   └── continue 跳过本次
│   │
│   └── 循环嵌套
│       ├── 外层走一步，内层跑一圈
│       └── 变量名要不同
│
├── 阶段3：数据容器
│   ├── 列表 list
│   │   ├── [元素1, 元素2, ...]
│   │   ├── 访问：列表[编号]（从0开始）
│   │   ├── 增：append() / insert()
│   │   ├── 删：remove() / del / pop()
│   │   ├── 改：列表[编号] = 新值
│   │   └── 切片：列表[起点:终点:步长]
│   │
│   ├── 字典 dict
│   │   ├── {"键": 值, ...}
│   │   ├── 访问：字典["键"] / .get()
│   │   ├── 增/改：字典["键"] = 值
│   │   ├── 删：del / .pop()
│   │   └── 遍历：for k, v in .items()
│   │
│   ├── 元组 tuple
│   │   ├── (元素1, 元素2, ...)
│   │   ├── 不能修改（只读）
│   │   └── 可解包：a, b = (1, 2)
│   │
│   └── 集合 set
│       ├── {元素1, 元素2, ...}
│       ├── 自动去重
│       └── 常用：list(set(列表)) 去重
│
├── 阶段4：函数与模块
│   ├── 函数基础
│   │   ├── def 函数名(参数):
│   │   ├── return 返回值
│   │   ├── 默认参数：def f(a, b=10)
│   │   └── 必须先定义再调用
│   │
│   ├── 函数进阶
│   │   ├── *args → 元组
│   │   ├── **kwargs → 字典
│   │   └── lambda 参数: 表达式
│   │
│   ├── 模块 import
│   │   ├── import 模块名
│   │   ├── from 模块名 import 功能
│   │   ├── import 模块名 as 别名
│   │   └── 第三方模块：pip install
│   │
│   └── 常用内置模块
│       ├── math：sqrt/ceil/floor
│       ├── random：randint/choice/shuffle
│       ├── datetime：now/strftime
│       ├── os：getcwd/path.join/path.exists
│       └── json：dumps/loads（AI必备！）
│
├── 阶段5：文件操作与异常处理
│   ├── 文件读写
│   │   ├── with open("文件", "模式", encoding="utf-8") as f:
│   │   ├── 模式：r读 / w写(覆盖) / a追加
│   │   ├── f.write() / f.read() / f.readlines()
│   │   └── 必须指定 encoding="utf-8"
│   │
│   ├── 异常处理
│   │   ├── try / except / finally
│   │   ├── 常见异常：ValueError/TypeError/FileNotFoundError
│   │   ├── raise 主动抛出
│   │   └── 关键操作都要加try-except
│   │
│   └── 综合实战
│       ├── 函数封装每个功能
│       ├── 文件操作加异常处理
│       ├── 日志记录关键操作
│       └── if __name__ == "__main__":
│
├── 阶段6：正则表达式（新增）
│   ├── re模块基础
│   │   ├── re.match() → 从开头匹配
│   │   ├── re.search() → 搜索第一个
│   │   ├── re.findall() → 查找所有
│   │   └── re.sub() → 替换匹配内容
│   │
│   ├── 正则语法
│   │   ├── 字符类：[abc] [^abc] [a-z]
│   │   ├── 量词：* + ? {n} {n,m}
│   │   ├── 元字符：\d \w \s \b ^ $
│   │   └── 分组：() 捕获组
│   │
│   ├── 匹配模式
│   │   ├── 贪婪匹配：.*
│   │   ├── 非贪婪匹配：.*?
│   │   └── re.compile() 预编译
│   │
│   └── AI实战
│       ├── 文本清洗：去除空白、特殊字符
│       ├── 信息提取：数字、邮箱、URL
│       └── 内容过滤：敏感词、无效内容
│
├── 阶段7：面向对象编程（新增）
│   ├── 类的定义
│   │   ├── class 类名:
│   │   ├── __init__(self, 参数) 构造方法
│   │   ├── self 参数（实例引用）
│   │   └── 实例化：obj = 类名()
│   │
│   ├── 属性与方法
│   │   ├── 实例属性：self.属性名
│   │   ├── 类属性：类名.属性名
│   │   ├── 实例方法：def 方法名(self)
│   │   └── 私有属性：__属性名（外部不可访问）
│   │
│   ├── 继承与多态
│   │   ├── class 子类(父类):
│   │   ├── super() 调用父类方法
│   │   ├── 方法重写：子类覆盖父类方法
│   │   └── 多态：同一接口不同实现
│   │
│   └── 高级特性
│       ├── __slots__：限制实例属性
│       ├── @property：属性访问控制
│       ├── 多重继承：class C(A, B)
│       └── isinstance()：类型检查
│
├── 阶段8：迭代器生成器与装饰器（新增）
│   ├── 迭代器
│   │   ├── __iter__() 返回迭代器对象
│   │   ├── __next__() 返回下一个元素
│   │   ├── StopIteration 结束迭代
│   │   └── iter() / next() 内置函数
│   │
│   ├── 生成器
│   │   ├── yield 关键字（暂停执行）
│   │   ├── 生成器函数：def func(): yield
│   │   ├── 生成器表达式：(x for x in list)
│   │   └── 内存高效：按需生成元素
│   │
│   ├── 装饰器
│   │   ├── @装饰器名 语法糖
│   │   ├── 闭包：函数嵌套函数
│   │   ├── functools.wraps 保留元信息
│   │   └── 带参数装饰器
│   │
│   └── 高阶函数
│       ├── map(func, iterable)
│       ├── filter(func, iterable)
│       ├── sorted(iterable, key=func)
│       └── lambda 匿名函数
│
└── 阶段9：多线程多进程并发（新增）
    ├── 多线程 threading
    │   ├── threading.Thread(target=func)
    │   ├── t.start() / t.join()
    │   ├── threading.Lock() 互斥锁
    │   └── 线程池：concurrent.futures.ThreadPoolExecutor
    │
    ├── 多进程 multiprocessing
    │   ├── multiprocessing.Process(target=func)
    │   ├── p.start() / p.join()
    │   ├── multiprocessing.Pool 进程池
    │   └── Manager 进程间通信
    │
    ├── 异步编程 asyncio
    │   ├── async def 异步函数
    │   ├── await 等待协程
    │   ├── asyncio.run() 运行事件循环
    │   └── asyncio.gather() 并发执行
    │
    └── AI实战场景
        ├── 并发调用AI模型接口
        ├── 批量处理大量文档
        ├── 异步文件读写优化
        └── 任务调度与进度管理
```
