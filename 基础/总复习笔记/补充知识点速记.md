## 阶段1：Python初相识

### 1. PEP8代码规范
- **变量命名**：小写+下划线（`user_name`）
- **注释规范**：`# 后面加空格`，文档字符串用`"""`
- **空格规范**：运算符两边、逗号后面加空格
- **禁止关键字**：`if`、`for`、`class`等不能做变量名

### 2. 完整运算符体系
- **赋值运算符**：`= += -= *= /= //= %= **=`
- **逻辑运算符**：`and`（与）、`or`（或）、`not`（非）
- **短路特性**：`and`遇False停止，`or`遇True停止
- **优先级**：`()` > `**` > `*/%` > `+/-` > 比较 > `not` > `and` > `or`
- **实用技巧**：`值 or 默认值`（设置默认值）

### 3. 字符串完整体系
- **索引**：`text[0]`正向，`text[-1]`反向
- **切片**：`text[start:end:step]`，终点不包含
- **去空格**：`strip()`去前后，`lstrip()`去左，`rstrip()`去右
- **大小写**：`upper()`大写，`lower()`小写，`title()`首字母大写
- **查找**：`find()`返回位置，`count()`统计次数
- **替换**：`replace(旧, 新)`
- **分割**：`split(分隔符)` → 列表
- **拼接**：`分隔符.join(列表)` → 字符串
- **判断**：`isdigit()`数字，`isalpha()`字母，`startswith()`/`endswith()`
- **转义**：`\n`换行，`\t`制表，`\\`反斜杠
- **原始字符串**：`r"内容"`不转义（路径常用）

### 4. print进阶
- **sep参数**：多个值之间的分隔符（默认空格）
- **end参数**：结尾字符（默认换行`\n`）
- **示例**：`print("2024", "01", "15", sep="-")` → `2024-01-15`

### 5. 报错基础理论
- **SyntaxError**：语法错（中文符号、括号不匹配、忘加冒号）
- **TypeError**：类型错（字符串和数字相加、函数参数类型不对）
- **ValueError**：值错（字符串转数字但内容不合法、删除不存在的元素）
- **看报错步骤**：文件名 → 行号 → 代码 → 错误类型 → 错误描述

### 6. 浮点数精度
- **精度问题**：`0.1 + 0.2 = 0.30000000000000004`（不精确）
- **原因**：计算机用二进制存小数，有限位数导致误差
- **比较小数**：用`round()`或`math.isclose()`，不要直接`==`
- **精确计算**：用`decimal.Decimal`，传字符串参数
- **AI开发**：涉及金额、费用计算，用`Decimal`

### 7. 编码基础
- **UTF-8**：国际通用，支持所有语言，推荐用
- **GBK**：中国国标，Windows默认（容易出问题）
- **ASCII**：只支持英文
- **乱码原因**：编码和解码用的规则不一致
- **文件读写**：必须加`encoding="utf-8"`
- **字符串转字节**：`encode("utf-8")`
- **字节转字符串**：`decode("utf-8")`
- **AI开发**：所有文本处理统一用UTF-8

## 阶段2：条件判断与循环

### 1. is与==的本质区别
- **==**：比较值是否相等（内容一样就行）
- **is**：比较是否是同一个对象（内存地址相同）
- **判断None**：必须用`is None`，不要用`== None`
- **列表、字典比较值**：用`==`，不要用`is`
- **数字缓存**：-5到256范围内`is`可能为True（Python缓存机制）
- **日常开发**：99%用`==`，只有判断None时用`is`

### 2. and/or/not完整逻辑运算
- **and**：全部条件为True才True（一假即假）
- **or**：任一条件为True就True（一真即真）
- **not**：取反，True变False，False变True
- **优先级**：`not` > `and` > `or`（不确定就加括号）
- **or实用技巧**：`值 or 默认值`
- **条件太长**：拆成变量，提高可读性

### 3. break/continue完整场景
- **break**：彻底结束整个循环
- **continue**：跳过本轮，进入下一轮
- **break典型场景**：搜索到目标就停止
- **continue典型场景**：跳过无效数据
- **for...else**：循环没被break时执行else
- **嵌套循环**：break只跳出一层

## 阶段3：数据容器

### 1. 可变对象与不可变对象
- **不可变**：int、float、str、tuple（创建后不能改）
- **可变**：list、dict、set（可以随时修改）
- **赋值可变对象**：是引用，不是复制
- **复制列表**：用切片`[:]`或`.copy()`
- **函数传列表**：会修改原数据，要先复制
- **AI开发**：处理数据时保护原数据，用副本操作

### 2. 容器通用操作
- **len(容器)**：获取元素个数
- **值 in 容器**：判断是否存在（字典判断键）
- **切片[start:end:step]**：取一部分，终点不包含
- **切片不会报错**，索引会报错
- **[::-1]**：反转容器
- **[:N]**：取前N个，`[-N:]`取后N个
- **AI开发**：统计数量、判断存在、提取片段

### 3. 字典Key限制与遍历
- **Key必须是不可变对象**：str、int、tuple
- **Key不能是**：list、dict、set（可变对象）
- **Key不能重复**，重复会被覆盖
- **遍历键值对**：`for k, v in dict.items()`
- **只遍历键**：`for k in dict`或`for k in dict.keys()`
- **只遍历值**：`for v in dict.values()`
- **嵌套字典**：逐层访问`dict["外层"]["内层"]`
- **字典推导式**：`{k: v for k, v in dict.items() if 条件}`

## 阶段4：函数与模块

### 1. 局部变量与全局变量作用域
- **局部变量**：函数内创建，函数外访问不到
- **全局变量**：函数外创建，整个文件都能用
- **函数内读取全局变量**：可以直接读
- **函数内修改全局变量**：必须加`global`声明
- **LEGB顺序**：Local → Enclosing → Global → Built-in
- **AI开发**：配置信息用全局变量，函数内尽量用局部变量

### 2. 函数无return默认返回None
- **没有return** → 返回None
- **return后面没值** → 返回None
- **return会立即结束函数**
- **所有if分支都要有return**
- **print是打印，return是返回**（不一样！）
- **AI开发**：接口调用函数失败时返回None
- **判断None**：用`is None`，不要用`== None`

### 3. 函数文档字符串标准写法
- **位置**：函数开头第一行（用`"""`包起来）
- **内容**：功能说明 + 参数说明 + 返回值说明
- **参数格式**：`参数名 (类型): 说明`
- **返回格式**：`返回类型: 说明`
- **查看文档**：`函数名.__doc__`或`help(函数名)`
- **AI开发**：封装接口函数必须写文档字符串

### 4. json模块详解
- **dumps(字典)**：字典 → JSON字符串
- **loads(字符串)**：JSON字符串 → 字典
- **dump(字典, 文件)**：字典 → JSON文件
- **load(文件)**：JSON文件 → 字典
- **ensure_ascii=False**：中文正常显示
- **indent=2**：美化输出（缩进）
- **AI开发**：解析大模型返回的JSON数据
- **JSON格式要求**：双引号、不能单引号

## 阶段5：文件操作与异常处理

### 1. 绝对路径与相对路径
- **绝对路径**：从盘符开始（`C:\Users\...`）
- **相对路径**：从当前目录开始（`./data/file.txt`）
- **.**：当前目录，`..`上级目录
- **Windows路径**：用原始字符串`r"路径"`
- **AI开发**：配置文件用相对路径，日志用绝对路径
- **路径拼接**：用`os.path.join()`，不要用+号

### 2. os模块路径操作
- **os.path.join(a, b)**：拼接路径（推荐）
- **os.path.exists(path)**：判断路径是否存在
- **os.path.basename(path)**：获取文件名
- **os.path.dirname(path)**：获取目录
- **os.path.splitext(file)**：分离文件名和扩展名
- **os.path.isfile(path)**：判断是否是文件
- **os.path.isdir(path)**：判断是否是目录
- **os.getcwd()**：获取当前目录
- **os.mkdir(dir)**：创建目录
- **os.makedirs(a/b/c)**：创建多层目录
- **os.remove(file)**：删除文件
- **AI开发**：路径处理全部用os模块

### 3. 文件编码规范
- **读写文件必须指定**`encoding="utf-8"`
- **Windows默认GBK**，Python默认UTF-8
- **乱码原因**：编码和解码用的规则不一致
- **AI开发**：所有文本处理统一用UTF-8
- **JSON保存中文**：加`ensure_ascii=False`
- **遇到编码错误**：尝试其他编码（如GBK）
- **跨平台项目**：必须指定UTF-8

## 阶段6：正则表达式（新增）

### 1. re模块基础
- **re.match(pattern, text)**：从开头匹配（不常用）
- **re.search(pattern, text)**：搜索第一个匹配
- **re.findall(pattern, text)**：查找所有匹配（返回列表）
- **re.sub(pattern, repl, text)**：替换匹配内容
- **re.compile(pattern)**：预编译正则（提高效率）
- **AI开发**：清洗文本、提取信息、过滤内容

### 2. 正则语法速查
- **字符类**：`[abc]`匹配a/b/c，`[^abc]`匹配非a/b/c，`[a-z]`匹配小写字母
- **量词**：`*`0次或多次，`+`1次或多次，`?`0次或1次，`{n}`n次，`{n,m}`n到m次
- **元字符**：`\d`数字，`\w`字母数字下划线，`\s`空白，`\b`单词边界，`.`任意字符，`^`开头，`$`结尾
- **分组**：`()`捕获组，`(?:...)`非捕获组，`(?P<name>...)`命名分组
- **特殊字符转义**：`.` `*` `?` `(` `)` `[` `]` `{` `}` `^` `$` `\`

### 3. 匹配模式标志
- **re.DOTALL**：`.`匹配换行符
- **re.MULTILINE**：`^`和`$`匹配每行
- **re.IGNORECASE**：忽略大小写
- **re.VERBOSE**：忽略空格和注释（用于复杂正则）

### 4. 贪婪与非贪婪
- **贪婪匹配**：`.*`尽可能多匹配
- **非贪婪匹配**：`.*?`尽可能少匹配（常用）
- **示例**：`<div>内容</div>`用`<.*>`会匹配到最后一个`</div>`，用`<.*?>`才正确

## 阶段7：面向对象编程（新增）

### 1. 类定义基础
- **class 类名:**：定义类（大驼峰命名）
- **__init__(self, 参数)**：构造方法（初始化对象）
- **self**：实例引用（必须作为第一个参数）
- **实例化**：`obj = 类名(参数)`
- **实例属性**：`self.属性名 = 值`
- **实例方法**：`def 方法名(self, 参数)`

### 2. 私有属性与方法
- **私有属性**：`self.__属性名`（外部不可访问）
- **私有方法**：`def __方法名(self)`（外部不可访问）
- **访问私有属性**：通过公共方法或property装饰器
- **AI开发**：API密钥、配置信息用私有属性

### 3. 继承与多态
- **继承**：`class 子类(父类):`
- **调用父类方法**：`super().方法名()`
- **方法重写**：子类覆盖父类方法
- **多态**：同一接口不同实现
- **多重继承**：`class C(A, B)`（注意MRO顺序）

### 4. 高级特性
- **__slots__**：限制实例属性，节省内存
- **@property**：属性访问控制（getter）
- **@属性名.setter**：属性设置控制（setter）
- **isinstance(obj, 类)**：类型检查

## 阶段8：迭代器生成器与装饰器（新增）

### 1. 迭代器
- **迭代器协议**：实现`__iter__()`和`__next__()`方法
- **__iter__()**：返回迭代器对象（通常返回self）
- **__next__()**：返回下一个元素，没有时抛`StopIteration`
- **内置函数**：`iter(obj)`获取迭代器，`next(obj)`获取下一个
- **特性**：迭代器只能遍历一次

### 2. 生成器
- **yield关键字**：暂停执行，返回一个值
- **生成器函数**：`def func(): yield x`
- **生成器表达式**：`(x for x in list)`（圆括号）
- **特性**：内存高效，按需生成元素
- **AI开发**：分批处理大文件、大数据流

### 3. 装饰器
- **装饰器函数**：接收函数，返回包装函数
- **@语法糖**：`@decorator def func():`
- **functools.wraps**：保留原函数元信息（必须加）
- **带参数装饰器**：三层嵌套函数
- **应用场景**：日志记录、重试机制、缓存、权限检查
- **AI开发**：为API调用添加重试、缓存结果

### 4. 高阶函数
- **map(func, iterable)**：对每个元素应用函数
- **filter(func, iterable)**：过滤满足条件的元素
- **sorted(iterable, key=func)**：按key排序
- **lambda**：匿名函数（简单逻辑用）

## 阶段9：多线程多进程并发（新增）

### 1. 多线程 threading
- **threading.Thread(target=func, args=(arg1,))**：创建线程
- **t.start()**：启动线程
- **t.join()**：等待线程结束
- **threading.Lock()**：互斥锁（保护共享资源）
- **concurrent.futures.ThreadPoolExecutor**：线程池（推荐）
- **适用场景**：IO密集型任务（网络请求、文件读写）

### 2. 多进程 multiprocessing
- **multiprocessing.Process(target=func)**：创建进程
- **p.start()**：启动进程
- **p.join()**：等待进程结束
- **multiprocessing.Pool**：进程池
- **multiprocessing.Manager()**：进程间共享数据
- **Windows注意**：多进程必须放在`if __name__ == "__main__":`内
- **适用场景**：CPU密集型任务（数据处理、计算）

### 3. asyncio异步编程
- **async def**：定义异步函数
- **await**：等待协程完成
- **asyncio.run()**：运行事件循环
- **asyncio.gather()**：并发执行多个协程
- **asyncio.to_thread()**：把同步函数包装成异步
- **适用场景**：IO密集型任务（异步网络请求）

### 4. GIL全局解释器锁
- **GIL**：Python的全局解释器锁，同一时刻只有一个线程执行Python字节码
- **多线程**：IO密集型效率高，CPU密集型受限
- **多进程**：绕过GIL，充分利用多核CPU
- **AI开发**：并发调用API用多线程/线程池，批量数据处理用多进程

### 2. 批量处理文本文件
```python
import os

def process_files(input_dir, output_dir):
    if not os.path.exists(output_dir):
        os.makedirs(output_dir)
    
    for filename in os.listdir(input_dir):
        if filename.endswith(".txt"):
            input_path = os.path.join(input_dir, filename)
            output_path = os.path.join(output_dir, f"processed_{filename}")
            
            with open(input_path, "r", encoding="utf-8") as f:
                content = f.read()
            
            cleaned = content.strip().lower()
            
            with open(output_path, "w", encoding="utf-8") as f:
                f.write(cleaned)
```

import functools

def retry(max_retries=3, delay=1):
    """重试装饰器"""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries - 1:
                        raise
                    time.sleep(delay * (attempt + 1))
            return None
        return wrapper
    return decorator

import concurrent.futures

def process_batch(prompts):
    """并发处理一批提示词"""
    results = []
    with concurrent.futures.ThreadPoolExecutor(max_workers=5) as executor:
        future_to_prompt = {executor.submit(call_ai_api, p): p for p in prompts}
        for future in concurrent.futures.as_completed(future_to_prompt):
            prompt = future_to_prompt[future]
            try:
                result = future.result()
                results.append({"prompt": prompt, "result": result})
            except Exception as e:
                results.append({"prompt": prompt, "error": str(e)})
    return results
