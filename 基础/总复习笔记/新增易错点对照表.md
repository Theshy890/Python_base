## 阶段1：Python初相识

### 1. PEP8代码规范易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `userName = "张三"` | `user_name = "张三"` | 变量名用小写+下划线 |
| `#注释` | `# 注释` | 注释符号后加空格 |
| `x=1+2` | `x = 1 + 2` | 运算符两边加空格 |
| `my_list=[1,2,3]` | `my_list = [1, 2, 3]` | 逗号后加空格 |
| `if = 10` | `condition = 10` | 不能用关键字做变量名 |

### 2. 运算符易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `a = a + 1` 写成 `a == a + 1` | `a += 1` 或 `a = a + 1` | `=`赋值，`==`比较 |
| `and`和`or`优先级搞混 | 不确定就加括号 | `and`优先级高于`or` |
| 以为`or`返回True/False | `"" or "默认"` 返回 `"默认"` | `or`返回第一个为真的值 |
| `-2**2` 以为是4 | `(-2)**2` 才是4 | `-2**2` 是 `-(2**2)` = -4 |

### 3. 字符串操作易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `text[10]` 索引越界 | 先用 `len(text)` 检查长度 | 索引不能超出范围 |
| `find()`找不到返回-1 | 用 `if text.find("x") != -1:` 判断 | 不是报错，是返回值 |
| `split()`后忘记是列表 | `words[0]` 取第一个元素 | 结果是列表 |
| `join()`参数搞错 | `" ".join(words)` | 不是 `words.join(" ")` |
| 路径反斜杠转义 | 用原始字符串 `r"C:\path"` | `\U` `\A` 会被当成转义 |

### 4. 报错识别易错点

| 错误类型 | 常见原因 | 解决方法 |
|---------|---------|---------|
| `SyntaxError` | 中文符号、括号不匹配、忘加冒号 | 检查语法格式 |
| `TypeError` | 字符串和数字相加、函数参数类型不对 | 类型转换或检查参数 |
| `ValueError` | 字符串转数字但内容不合法 | 确保内容格式正确 |
| 不知道看哪一行报错 | 报错信息太长 | 看最后一行（错误类型）和倒数第三行（出错代码） |

### 5. 浮点数精度易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `0.1 + 0.2 == 0.3` | `math.isclose(0.1 + 0.2, 0.3)` | 浮点数有精度误差 |
| 金额计算用float | 用 `decimal.Decimal` | 涉及金额要精确计算 |
| `Decimal(0.1)` | `Decimal("0.1")` | 传字符串参数，不是浮点数 |

### 6. 编码易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `open("file.txt", "r")` | `open("file.txt", "r", encoding="utf-8")` | 必须指定编码 |
| Windows下写文件乱码 | 始终指定 `encoding="utf-8"` | 系统默认GBK，Python默认UTF-8 |
| `UnicodeDecodeError` | 确认文件编码，用对应编码解码 | 用错编码解码会报错 |

## 阶段2：条件判断与循环

### 1. is与==易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `a is b` 对列表/字典 | `a == b` | `is`比较内存地址，不是值 |
| `result == None` | `result is None` | 判断None必须用`is` |
| 以为`is`总是比`==`安全 | 只有判断None时用`is` | 超出缓存范围的数字`is`会返回False |

### 2. 逻辑运算易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `not x > 5` 理解错 | `not (x > 5)` | 加括号明确优先级 |
| 条件太长看不懂 | 拆成变量 `is_valid = a and b` | 提高可读性 |
| `and`/`or`优先级搞混 | 不确定就加括号 | `not` > `and` > `or` |

### 3. break/continue易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| break后else也执行了 | break打断循环，else不执行 | 这是正常行为 |
| continue后面的代码不执行 | 把continue放在本轮最后 | continue跳过剩余代码 |
| 嵌套循环中break只跳出一层 | 多层跳出用函数return或标志变量 | break只跳出最内层 |
| while里忘记更新条件 | continue前确保条件变量会更新 | 避免死循环 |

## 阶段3：数据容器

### 1. 可变/不可变对象易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 修改列表B，列表A也跟着变 | `B = A[:]` 或 `B = A.copy()` | `B = A`是引用，不是复制 |
| 函数里修改参数，外面也变了 | 函数里先复制再修改 | 列表是可变对象，传的是引用 |
| 以为字符串可以修改单个字符 | 只能创建新字符串 | 字符串是不可变对象 |
| 元组里嵌套了列表 | 元组里的列表可以修改 | 元组本身不可变，但里面的列表可变 |

### 2. 容器通用操作易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `len()`对字典返回值的数量 | `len(dict)`返回键值对数 | 字典长度是键值对数量 |
| `in`判断字典时忘记判断的是键 | `"name" in user`判断键 | `in`默认判断键，不是值 |
| 切片`[1:4]`以为包含4 | `[1:4]`取的是1,2,3 | 切片终点不包含 |
| 索引`[10]`报错但切片`[10:]`不报错 | 切片更宽容，不会报错 | 索引会检查范围 |

### 3. 字典Key与遍历易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 用列表做字典Key报错 | 用字符串、数字或元组 | 列表是可变的，不能做Key |
| 遍历字典只拿到键 | 用 `dict.items()` 遍历键值对 | `for k in dict`只遍历键 |
| 嵌套字典取值错误 | `dict["外层"]["内层"]` | 逐层访问 |
| 字典Key重复 | 确保Key唯一 | 后面的覆盖前面的 |

## 阶段4：函数与模块

### 1. 变量作用域易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `UnboundLocalError` | 加 `global 变量名` 声明 | 函数内修改全局变量要声明 |
| 函数外访问不到函数内变量 | 用 `return` 返回值 | 局部变量作用域仅限函数内 |
| 全局变量被意外修改 | 尽量避免，或用 `global` 明确声明 | 函数内尽量用局部变量 |
| 嵌套函数变量混乱 | 每层函数独立变量名 | 理解LEGB查找顺序 |

### 2. 函数返回值易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 函数调用后得到None | 检查函数是否有return语句 | 没有return返回None |
| 某些情况返回None | 所有分支都要有return | if分支没写return |
| 以为print就是return | 用return返回值 | print是打印，return是返回 |
| return后代码不执行 | return放在最后 | return会立即结束函数 |

### 3. 文档字符串易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 文档字符串位置不对 | 放在函数开头第一行 | 必须紧跟def下一行 |
| 文档字符串格式混乱 | 用标准格式：参数、返回、示例 | 统一格式便于阅读 |
| 忘记写文档字符串 | 养成习惯，每个函数都写 | AI开发必须写文档 |
| 文档字符串和实际不符 | 同步更新文档 | 代码改了文档也要改 |

### 4. json模块易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `json.loads()`报错 | JSON必须用双引号 | JSON字符串格式不对（如单引号） |
| 中文显示Unicode | dumps时加 `ensure_ascii=False` | 保证中文正常显示 |
| `json.load()`和`json.loads()`搞混 | load文件，loads字符串 | 注意区分 |
| 解析后取不到值 | 先print看结构 | 键名写错或层级不对 |

## 阶段5：文件操作与异常处理

### 1. 路径易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `FileNotFoundError` | 检查路径拼写，确认文件存在 | 路径写错了或文件不存在 |
| Windows路径反斜杠报错 | 用原始字符串 `r"C:\path"` | `\U` `\A`被当成转义字符 |
| 相对路径找不到文件 | 用绝对路径或先切换目录 | 当前工作目录不对 |
| 路径拼接用字符串相加 | 用 `os.path.join()` | `"folder" + "file.txt"`变成`"folderfile.txt"` |

### 2. os模块路径操作易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 路径拼接用`+`号 | 用 `os.path.join("a", "b")` | `"a" + "b"`变成`"ab"` |
| Windows路径报错 | 用原始字符串 `r"路径"` 或 `os.path.join()` | 反斜杠被当成转义 |
| 文件不存在报错 | 先用 `os.path.exists()` 判断 | 没检查路径是否存在 |
| 跨平台路径不兼容 | 用 `os.path.join()` 自动适配 | Windows用`\`，Mac用`/` |

### 3. 文件编码易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 中文显示乱码 | 始终加 `encoding="utf-8"` | 没指定encoding或编码不对 |
| `UnicodeDecodeError` | 确认文件编码，用对应编码解码 | 用错编码解码 |
| Windows和Mac显示不同 | 统一用UTF-8 | 系统默认编码不同 |
| JSON文件中文变Unicode | `json.dump()`时加参数 | 没加 `ensure_ascii=False` |

## 阶段6：正则表达式（新增）

### 1. re模块方法易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 用`match()`匹配任意位置 | 用`search()`或`findall()` | `match()`只从开头匹配 |
| `findall()`返回列表忘了判断 | 先判断`if len(results) > 0:` | 返回空列表不报错 |
| 忘记导入re模块 | `import re` | 必须先导入 |
| 正则字符串转义问题 | 用原始字符串 `r"正则"` | `\d`变成`\\d` |

### 2. 正则语法易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `.`匹配不到换行符 | 加`re.DOTALL`标志 | 默认`.`不匹配`\n` |
| `^`和`$`匹配每行 | 加`re.MULTILINE`标志 | 默认只匹配整个字符串首尾 |
| 贪婪匹配吞掉太多 | 用非贪婪`.*?` | `.*`会尽可能多匹配 |
| 特殊字符未转义 | 转义`.` `*` `?` `(` `)`等 | 这些是正则元字符 |

### 3. 分组与引用易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 分组引用用`$1` | Python用`\1`或`group(1)` | 替换用`\1`，提取用`group()` |
| 括号被当成分组 | 用非捕获组`(?:...)` | 不想捕获就用非捕获组 |
| 命名分组语法错 | `(?P<name>pattern)` | 命名分组格式 |

## 阶段7：面向对象编程（新增）

### 1. 类定义易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `__init__`漏写self | `def __init__(self, ...)` | 第一个参数必须是self |
| 方法里忘记用self | `self.属性名` | 访问实例属性必须用self |
| 类名用小写 | `class MyClass:` | 类名用大驼峰命名 |
| 实例化时漏写括号 | `obj = MyClass()` | 必须加括号 |

### 2. 继承与super易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 子类没调用父类`__init__` | `super().__init__(...)` | 需要手动调用 |
| Python2的super写法 | `super(子类, self).__init__()` | Python3可以简化 |
| 多重继承MRO混乱 | 了解C3算法，避免复杂继承 | 继承顺序影响方法调用 |
| 私有属性被继承 | 私有属性`__name`不可继承 | 子类访问不到父类私有属性 |

### 3. 属性访问易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 直接访问私有属性 | 通过公共方法或property | `obj.__attr`会报错 |
| property装饰器位置错 | `@property`在getter方法上 | 必须先定义getter |
| setter装饰器名错 | `@属性名.setter` | setter装饰器名称要匹配 |

## 阶段8：迭代器生成器与装饰器（新增）

### 1. 迭代器易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 迭代器只能遍历一次 | 需要多次遍历就转成列表 | `list(iterator)` |
| 手动调用`__next__()` | 用`next()`内置函数 | `next(iter_obj)` |
| 忘记实现`__iter__()` | 返回`self` | 迭代器协议需要两个方法 |

### 2. 生成器易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 生成器函数直接返回列表 | 用yield逐个产出 | return会结束生成器 |
| 调用生成器函数就执行 | 只有迭代时才执行 | `gen = func()`不执行，`for x in gen`才执行 |
| 生成器表达式用方括号 | 用圆括号`(x for x in list)` | 方括号是列表推导式 |

### 3. 装饰器易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 装饰器函数没return | `return wrapper` | 装饰器必须返回包装函数 |
| 忘记保留原函数信息 | `@functools.wraps(func)` | 不加wraps会丢失函数名等信息 |
| 带参数装饰器结构错 | 三层嵌套：外层接收参数，中层接收函数，内层执行 | 需要三层函数 |
| 装饰器应用顺序搞反 | 靠近函数的先执行 | `@A @B def f()`：B先应用，A后应用 |

## 阶段9：多线程多进程并发（新增）

### 1. 多线程易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 线程函数传参错 | `Thread(target=func, args=(arg1,))` | args必须是元组 |
| 主线程提前退出 | 用`t.join()`等待子线程 | 主线程结束会杀掉子线程 |
| 共享资源竞争 | 用`threading.Lock()`保护 | 多个线程同时修改同一变量会出错 |
| GIL限制CPU并行 | CPU密集型用多进程 | 多线程适合IO密集型 |

### 2. 多进程易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| Windows下多进程写在`if __name__ == "__main__":`外 | 必须放在main判断内 | Windows需要重新导入模块 |
| 进程间共享变量 | 用`multiprocessing.Manager()` | 普通全局变量不共享 |
| 进程池任务太大 | 用`Pool.map()`分批处理 | 避免内存溢出 |
| 进程创建开销大 | 优先用进程池 | 反复创建进程效率低 |

### 3. 异步编程易错点

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| 普通函数用await | 只能await协程对象 | 普通函数需要用`asyncio.to_thread()` |
| 同步阻塞调用 | 用异步版本或`to_thread()` | 同步IO会阻塞事件循环 |
| 忘记`asyncio.run()` | 必须用run启动事件循环 | 协程不会自动执行 |

## 常见错误快速定位

### 看到报错先冷静，按以下步骤定位：

1. **看最后一行**：错误类型（TypeError/ValueError/SyntaxError等）
2. **看倒数第三行**：出错的代码
3. **看行号**：第几行出错
4. **看文件名**：哪个文件出错
5. **根据错误类型查表**：本文档上方有详细对照

### 常见错误类型速查

| 错误类型 | 可能原因 | 快速解决 |
|---------|---------|---------|
| `SyntaxError` | 语法错误 | 检查中文符号、括号、冒号 |
| `TypeError` | 类型错误 | 检查类型转换、参数类型 |
| `ValueError` | 值错误 | 检查数据格式、内容 |
| `NameError` | 变量未定义 | 检查变量名拼写、作用域 |
| `IndexError` | 索引越界 | 检查列表长度、索引范围 |
| `KeyError` | 字典键不存在 | 用get()或先判断键是否存在 |
| `FileNotFoundError` | 文件不存在 | 检查路径、用exists()判断 |
| `UnicodeDecodeError` | 编码错误 | 指定正确的encoding |
| `AttributeError` | 属性不存在 | 检查属性名拼写、对象类型 |
| `StopIteration` | 迭代器已空 | 检查迭代逻辑 |
| `RuntimeError` | 运行时错误 | 检查协程、线程等状态 |
