## 知识点 9.1：什么是并发编程

### ① 一句话通俗定义
**并发编程 = 让程序同时执行多个任务，提高效率。**

就像餐厅服务员：一个服务员同时照顾好几桌客人，而不是等一桌吃完再去服务下一桌。

### ② 生活例子类比

| 串行（一个一个做） | 并发（同时做） |
|-------------------|---------------|
| 先烧水，等水开了再泡茶 | 烧水的同时准备茶叶和杯子 |
| 先处理A任务，做完再处理B | A和B同时处理 |
| 效率低，等待时间长 | 效率高，充分利用时间 |

### ③ AI开发场景
| 场景 | 并发能做什么 |
|------|-------------|
| 批量调用AI接口 | 同时调用10个接口，节省90%时间 |
| 批量处理文档 | 同时处理多个文件 |
| 实时数据处理 | 同时接收和处理多个请求 |

## 知识点 9.2：线程 vs 进程

### ① 核心区别

| 维度 | 线程 | 进程 |
|------|------|------|
| **资源占用** | 小，共享进程内存 | 大，有独立内存空间 |
| **创建开销** | 小 | 大 |
| **通信方式** | 直接共享变量 | 需要IPC（进程间通信） |
| **适用场景** | IO密集型任务 | CPU密集型任务 |
| **数量限制** | 可以很多（上百个） | 不宜太多（几十个） |

### ② 什么时候用线程，什么时候用进程

```
任务类型判断：
├── IO密集型（等待时间长）：网络请求、文件读写
│   └── 用多线程（创建开销小）
└── CPU密集型（计算量大）：数据处理、模型训练
    └── 用多进程（利用多核CPU）
```

**AI开发中的典型场景**：
- 调用AI API接口 → **多线程**（大部分时间在等待网络响应）
- 本地模型推理 → **多进程**（充分利用多核CPU）

## 知识点 9.3：threading多线程

### ① 一句话通俗定义
**threading模块 = Python自带的多线程工具箱。**

### ② 语法说明

```python
import threading
import time

def task(name, delay):
    print(f"任务 {name} 开始")
    time.sleep(delay)
    print(f"任务 {name} 完成")

# 方式1：创建线程对象
thread1 = threading.Thread(target=task, args=("A", 2))
thread2 = threading.Thread(target=task, args=("B", 2))

# 启动线程
thread1.start()
thread2.start()

# 等待线程完成（可选）
thread1.join()
thread2.join()

print("所有任务完成")

# 输出：（两个任务同时进行，总共约2秒）
# 任务 A 开始
# 任务 B 开始
# 任务 A 完成
# 任务 B 完成
# 所有任务完成
```

### ③ 线程共享数据与锁

```python
import threading

counter = 0
lock = threading.Lock()  # 创建锁

def increment():
    global counter
    for _ in range(100000):
        lock.acquire()  # 获取锁
        counter += 1
        lock.release()  # 释放锁

thread1 = threading.Thread(target=increment)
thread2 = threading.Thread(target=increment)

thread1.start()
thread2.start()
thread1.join()
thread2.join()

print(f"最终结果：{counter}")  # 200000（正确）
```

**为什么需要锁**：多个线程同时修改同一个变量会导致数据混乱，锁确保同一时间只有一个线程在操作。

## 知识点 9.4：concurrent.futures线程池

### ① 一句话通俗定义
**线程池 = 预先创建好的线程集合，重复使用，避免频繁创建销毁线程。**

就像工厂里的流水线：工人（线程）已经准备好了，任务来了就直接分配，不用每次都招聘新工人。

### ② 语法说明

```python
from concurrent.futures import ThreadPoolExecutor
import time

def call_api(prompt):
    print(f"处理请求：{prompt}")
    time.sleep(1)  # 模拟网络延迟
    return f"AI回复：{prompt}"

# 创建线程池（最多5个线程）
with ThreadPoolExecutor(max_workers=5) as executor:
    # 提交任务
    prompts = ["你好", "什么是AI", "今天天气怎么样", "谢谢"]
    futures = [executor.submit(call_api, prompt) for prompt in prompts]

    # 获取结果
    for future in futures:
        result = future.result()
        print(result)

# 输出：（4个请求几乎同时开始，总共约1秒）
# 处理请求：你好
# 处理请求：什么是AI
# 处理请求：今天天气怎么样
# 处理请求：谢谢
# AI回复：你好
# AI回复：什么是AI
# AI回复：今天天气怎么样
# AI回复：谢谢
```

### ③ map方法——更简洁的写法

```python
from concurrent.futures import ThreadPoolExecutor

def process_item(item):
    return item * 2

with ThreadPoolExecutor(max_workers=3) as executor:
    items = [1, 2, 3, 4, 5]
    results = list(executor.map(process_item, items))

print(results)  # [2, 4, 6, 8, 10]
```

## 知识点 9.5：multiprocessing多进程

### ① 一句话通俗定义
**multiprocessing模块 = Python自带的多进程工具箱。**

### ② 语法说明

```python
import multiprocessing
import time

def heavy_computation(num):
    print(f"进程 {num} 开始计算")
    result = sum(i * i for i in range(1000000))
    print(f"进程 {num} 计算完成")
    return result

if __name__ == "__main__":
    # 创建进程
    processes = []
    for i in range(4):
        p = multiprocessing.Process(target=heavy_computation, args=(i,))
        processes.append(p)

    # 启动进程
    for p in processes:
        p.start()

    # 等待完成
    for p in processes:
        p.join()

    print("所有计算完成")
```

### ③ 进程池

```python
from multiprocessing import Pool

def square(x):
    return x * x

if __name__ == "__main__":
    with Pool(processes=4) as pool:
        results = pool.map(square, [1, 2, 3, 4, 5])

    print(results)  # [1, 4, 9, 16, 25]
```

## 知识点 9.6：concurrent.futures进程池

### ① 语法说明

```python
from concurrent.futures import ProcessPoolExecutor

def compute_factorial(n):
    result = 1
    for i in range(1, n+1):
        result *= i
    return result

with ProcessPoolExecutor(max_workers=4) as executor:
    numbers = [5, 10, 15, 20]
    results = list(executor.map(compute_factorial, numbers))

print(results)  # [120, 3628800, 1307674368000, 2432902008176640000]
```

## 知识点 9.7：AI开发实战——并发调用AI接口

### 场景1：批量调用AI API

```python
from concurrent.futures import ThreadPoolExecutor
import time

def call_ai_api(prompt, api_key):
    # 模拟API调用
    time.sleep(0.5)  # 网络延迟
    return {
        "prompt": prompt,
        "response": f"AI回答：{prompt}",
        "tokens": len(prompt) * 2
    }
# 待处理的请求
prompts = [
    "解释什么是机器学习",
    "Python和Java的区别",
    "如何学习AI开发",
]
# 单线程处理（约4秒）
start = time.time()
for prompt in prompts:
    call_ai_api(prompt, "sk-123456")
print(f"单线程耗时：{time.time()-start:.2f}秒")

# 多线程处理（约0.5秒）
start = time.time()
with ThreadPoolExecutor(max_workers=8) as executor:
    results = list(executor.map(lambda p: call_ai_api(p, "sk-123456"), prompts))
print(f"多线程耗时：{time.time()-start:.2f}秒")

# 打印结果
for result in results:
    print(f"问题：{result['prompt']}\n回答：{result['response']}\n---")
```

### 场景2：批量处理文档并调用AI

```python
from concurrent.futures import ThreadPoolExecutor
import os

def process_document(filepath):
    # 读取文件
    with open(filepath, "r", encoding="utf-8") as f:
        content = f.read()

    # 调用AI分析
    ai_result = f"分析完成：{os.path.basename(filepath)}，长度：{len(content)}"
    return ai_result

# 获取所有文档文件
documents = [f"docs/{f}" for f in os.listdir("docs") if f.endswith(".txt")]

# 并发处理
with ThreadPoolExecutor(max_workers=4) as executor:
    results = list(executor.map(process_document, documents))

for result in results:
    print(result)
```

### 场景3：带超时控制的并发调用

```python
from concurrent.futures import ThreadPoolExecutor, TimeoutError

def call_api_with_timeout(prompt):
    import time
    if len(prompt) > 10:
        time.sleep(3)  # 模拟超时
    return f"结果：{prompt}"

with ThreadPoolExecutor(max_workers=3) as executor:
    futures = {executor.submit(call_api_with_timeout, p): p for p in ["短", "中等长度的问题", "非常长的问题需要很多时间"]}

    for future, prompt in futures.items():
        try:
            result = future.result(timeout=2)  # 2秒超时
            print(f"成功：{prompt} -> {result}")
        except TimeoutError:
            print(f"超时：{prompt}")
```
