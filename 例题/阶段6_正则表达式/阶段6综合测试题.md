## 答案与解析

### 选择题答案
1. B - `\d` 匹配任意数字
2. B - `+` 表示1次或多次
3. B - 贪婪模式会匹配最长内容
4. C - `findall()` 返回列表
5. A - `\w+@\w+\.\w+` 可以匹配邮箱
6. B - `compile()` 预编译正则表达式

### 填空题答案
7. a或b或c；不是a且不是b且不是c的字符
8. 字母、数字、下划线；空白字符
9. 整个匹配内容；第一个分组的内容
10. `?`

### 编程题参考答案

#### 题目11参考代码
```python
import re

text = """
联系我们：
手机：13800138000，备用手机：13900139000
邮箱：support@example.com，hello@test.org
官网：https://www.example.com/path?query=1
文档：http://docs.test.com
"""

phones = re.findall(r"\d{11}", text)
emails = re.findall(r"[\w.-]+@[\w.-]+\.\w+", text)
urls = re.findall(r"https?://[\w.-]+(/[\w./?%&=-]*)?", text)

print(f"手机号：{phones}")
print(f"邮箱：{emails}")
print(f"URL：{urls}")
```

#### 题目12参考代码
```python
import re

user_input = "  你好啊！！！ 我想了解一下 AI 的应用场景...\n\n"

model_response = """
分析结果：
- 情感倾向：正面
- 置信度：0.92
- 关键词：["人工智能", "深度学习", "应用"]
"""

# 清洗用户输入
cleaned = user_input.strip()
cleaned = re.sub(r"[！。？、...]{2,}", "。", cleaned)
cleaned = re.sub(r"\s+", " ", cleaned)

# 提取结构化数据
sentiment = re.search(r"情感倾向：(\S+)", model_response).group(1)
confidence = float(re.search(r"置信度：(\d+\.?\d*)", model_response).group(1))
keywords = re.findall(r'"([^"]+)"', model_response)

print(f"清洗后的输入：{cleaned}")
print(f"情感倾向：{sentiment}")
print(f"置信度：{confidence}")
print(f"关键词：{keywords}")
```
