## 一、选择题（每题 1 个正确答案）

### 第 1 题（基础）
以下哪个变量名是**合法**的？

A. `1name`
B. `my-name`
C. `my_name`
D. `class`

<details>
<summary>点击查看答案</summary>

**答案：C**

**解析**：
- A 错误：变量名不能以数字开头。
- B 错误：变量名不能用减号 `-`，Python 会把它当成减法。
- C 正确：下划线是允许的，符合 PEP8 命名规范。
- D 错误：`class` 是 Python 的关键字，不能作为变量名。

**所属知识点**：变量命名规则
</details>

### 第 2 题（基础）
执行以下代码后，`result` 的值是多少？

```python
a = 5
b = 2
result = a // b
```

A. `2.5`
B. `2`
C. `3`
D. `1`

<details>
<summary>点击查看答案</summary>

**答案：B**

**解析**：`//` 是整除（地板除），表示取商的整数部分。`5 // 2 = 2`，余数被丢弃。注意和 `/` 普通除法区分。

**所属知识点**：算术运算符 `/` 与 `//` 的区别
</details>

### 第 3 题（易错）
以下代码的输出结果是什么？

```python
text = "Hello Python"
print(text.split(","))
```

A. `['Hello', 'Python']`
B. `['Hello Python']`
C. `['Hello', 'Python']`
D. 报错

<details>
<summary>点击查看答案</summary>

**答案：B**

**解析**：字符串里没有逗号 `,`，只有一个空格。`split(",")` 找不到分隔符，就返回包含原字符串的列表：`['Hello Python']`。

**所属知识点**：字符串 `split()` 方法的使用
</details>

---

### 第 4 题（易错）
以下代码的输出结果是什么？

```python
words = ["2024", "AI", "应用"]
print("-".join(words))
```

A. `2024 AI 应用`
B. `['2024', 'AI', '应用']`
C. `2024-AI-应用`
D. 报错

<details>
<summary>点击查看答案</summary>

**答案：C**

**解析**：`join()` 是字符串方法，用前面的字符串做"胶水"，把列表里的元素粘起来。`"-".join(words)` 就是用 `-` 连接列表元素。

**所属知识点**：字符串 `join()` 方法的语法
</details>

### 第 5 题（进阶）
以下代码执行后会输出什么？

```python
x = 0.1 + 0.2
print(x == 0.3)
```

A. `True`
B. `False`
C. 报错
D. `0.3`

<details>
<summary>点击查看答案</summary>

**答案：B**

**解析**：`0.1` 和 `0.2` 在二进制中都是无限循环小数，计算机存储时会截断，导致 `0.1 + 0.2` 实际上是 `0.30000000000000004`，不等于 `0.3`。

**所属知识点**：浮点数精度问题
</details>

### 第 7 题（易错）
补全代码，把文本按行分割成列表。

```python
article = "第一行。\n第二行。\n第三行。"
lines = article.split(____)
print(lines)
```

输出应为：`['第一行。', '第二行。', '第三行。']`

<details>
<summary>点击查看答案</summary>

**答案**：`"\n"`

**完整代码**：
```python
article = "第一行。\n第二行。\n第三行。"
lines = article.split("\n")
print(lines)
```

**解析**：`\n` 是换行符。`split("\n")` 会把字符串在换行处切开。注意 `split()` 只能用于字符串，不能用于列表。

**所属知识点**：转义字符 `\n`、字符串 `split()` 方法
</details>

### 第 8 题（进阶）
补全代码，计算并输出平均字数（保留 2 位小数）。

```python
articles = ["今天天气好", "Python很有趣", "学习使我快乐"]
total = len(____) + len(____) + len(____)

result = ____ / ____
print(____(result, ____))
```

<details>
<summary>点击查看答案</summary>

**答案**：`articles[0]`、`articles[1]`、`articles[2]`、`total`、`3`、`round`、`2`

**完整代码**：
```python
articles = ["今天天气好", "Python很有趣", "学习使我快乐"]
total = len(articles[0]) + len(articles[1]) + len(articles[2])

result = total / 3
print(round(result, 2))
```

**解析**：
- `articles[0]`、`articles[1]`、`articles[2]` 分别取出列表中的 3 个字符串。
- `len()` 计算每个字符串的长度。
- `total / 3` 得到平均值。
- `round(result, 2)` 把结果保留 2 位小数。

**所属知识点**：列表索引、`len()` 函数、`round()` 函数
</details>

## 三、代码实操题

### 第 9 题（综合）
**题目**：有一段英文文本，要求统计其中单词的数量，并输出前 3 个单词。

```python
article = "Python is great Python is easy to learn"
```
article
len(article)
**要求**：
1. 用空格把文章分割成单词列表；
2. 输出单词总数；
3. 输出前 3 个单词。

<details>
<summary>点击查看答案</summary>

**参考答案**：
```python
article = "Python is great Python is easy to learn"

# 1. 用空格分割成单词列表
words = article.split(" ")

# 2. 输出单词总数
print("单词总数：", len(words))

# 3. 输出前 3 个单词
print("前 3 个单词：", words[0], words[1], words[2])
```

**运行结果**：
```
单词总数： 8
前 3 个单词： Python is great
```

**逐行解析**：
- 第 1 行：定义字符串变量 `article`。
- 第 4 行：`split(" ")` 按空格分割字符串，返回列表。
- 第 7 行：`len(words)` 计算列表元素个数。
- 第 10 行：用索引 `words[0]`、`words[1]`、`words[2]` 取出前三个单词。

**所属知识点**：字符串 `split()`、`len()`、列表索引
</details>

### 第 10 题（综合 + 易错）
**题目**：某用户进行了 3 次 API 调用，每次费用分别是 `0.1` 元、`0.2` 元、`0.15` 元。请用精确的小数计算总费用，并输出 `"总费用：0.45元"`。

**要求**：
1. 使用 `Decimal` 进行精确计算；
2. 结果保留 2 位小数；
3. 输出格式如 `"总费用：0.45元"`。

<details>
<summary>点击查看答案</summary>

**参考答案**：
```python
from decimal import Decimal, getcontext

# 设置精度为10位有效数字
getcontext().prec = 10

# 定义每次费用
fee1 = Decimal("0.1")
fee2 = Decimal("0.2")
fee3 = Decimal("0.15")

# 计算总费用
total = fee1 + fee2 + fee3

# 保留2位小数并输出
print("总费用：" + str(round(total, 2)) + "元")
```

**运行结果**：
```
总费用：0.45元
```

**逐行解析**：
- 第 1 行：从 `decimal` 模块导入 `Decimal` 和 `getcontext`。
- 第 4 行：设置 Decimal 计算精度为 10 位有效数字。
- 第 7-9 行：用字符串创建精确的 Decimal 对象。注意必须传字符串，不能传浮点数。
- 第 12 行：Decimal 对象之间相加，结果仍然精确。
- 第 15 行：`round(total, 2)` 保留 2 位小数，`str()` 转成字符串后拼接输出。

**所属知识点**：`Decimal` 精确计算、`getcontext().prec`、字符串拼接
</details>
