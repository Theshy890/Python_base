## 四、参考答案与解析

### 选择题答案

#### 第 1 题
**答案：B**

**解析**：
1. `append("赵六")` 后：`["张三", "李四", "王五", "赵六"]`
2. `insert(1, "孙七")` 在位置 1 插入：`["张三", "孙七", "李四", "王五", "赵六"]`
3. `del names[0]` 删除第 0 个元素：`["孙七", "李四", "王五", "赵六"]`

#### 第 2 题
**答案：B**

**解析**：
- `get()` 是字典的安全访问方法，键不存在时返回 `None` 或指定的默认值。
- `[]` 访问不存在的键会报 `KeyError`。

#### 第 3 题
**答案：B**

**解析**：
- `b = a` 不是复制列表，而是让 `b` 和 `a` 指向同一个列表。
- 通过 `b` 修改 `[0]`，等价于通过 `a` 修改，所以 `a` 也变成 `[100, 2, 3]`。

#### 第 4 题
**答案：D**

**解析**：
- 字典的 key 必须是不可变对象：字符串、数字、元组都可以。
- 列表是可变对象，不能作为 key。

#### 第 5 题
**答案：B**

**解析**：
- `split()` 默认按空格切分，得到 `["Python", "is", "great"]`。
- `len(words)` 返回 3。

### 代码实践题答案

#### 第 9 题 参考代码

```python
scores = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 72},
    {"name": "王五", "score": 90},
    {"name": "赵六", "score": 68}
]

# 1. 计算平均分
total = 0
for item in scores:
    total = total + item["score"]

average = total / len(scores)
print("平均分：", average)

# 2. 找出最高分和最低分
highest = scores[0]["score"]
lowest = scores[0]["score"]

for item in scores:
    if item["score"] > highest:
        highest = item["score"]
    if item["score"] < lowest:
        lowest = item["score"]

print("最高分：", highest)
print("最低分：", lowest)

# 3. 输出大于等于80分的用户姓名
passed_names = []
for item in scores:
    if item["score"] >= 80:
        passed_names.append(item["name"])

print("大于等于80分的用户：", passed_names)
```

**逐行解析**：
- 第 7 行：定义累加器 `total`，初始为 0。
- 第 8-9 行：遍历每个用户字典，把 `score` 累加到 `total`。
- 第 11 行：平均分 = 总分 / 人数，`len(scores)` 获取列表长度。
- 第 14-15 行：先假设第一个分数是最高和最低。
- 第 17-21 行：遍历比较，更新最高分和最低分。
- 第 24 行：创建空列表，准备存放及格用户名。
- 第 25-27 行：遍历，分数 >= 80 就把名字加入列表。

#### 第 10 题 参考代码

```python
users = {
    "user1": {"name": "张三", "age": 25, "city": "北京"},
    "user2": {"name": "李四", "age": 30, "city": "上海"}
}

# 遍历外层字典
for user_id, user_info in users.items():
    print("用户ID:", user_id)

    # 遍历内层字典
    for key, value in user_info.items():
        print("  " + key + ":", value)

    print("---")
```

**逐行解析**：
- 第 6 行：`users.items()` 返回 `(user_id, user_info)` 对，外层循环拆包。
- 第 7 行：打印用户 ID。
- 第 10 行：`user_info.items()` 返回每个字段的 `(key, value)` 对。
- 第 11 行：前面加两个空格，实现缩进效果。
- 第 13 行：每个用户结束后打印分隔线。

#### 第 11 题 参考代码

```python
text = "Python is great python is awesome"

# 1. 先统一转小写，避免大小写问题
text_lower = text.lower()

# 2. 按空格切分
words = text_lower.split()
print("单词列表：", words)

# 3. 去重后统计不重复单词数
unique_words = set(words)
print("不重复单词数：", len(unique_words))

# 4. 判断 python 是否在文本中
if "python" in text_lower:
    print("文本中包含 python")
else:
    print("文本中不包含 python")
```

**逐行解析**：
- 第 4 行：`lower()` 把整段文本转成小写，这样 `"Python"` 和 `"python"` 会被视为同一个词。
- 第 7 行：`split()` 按空格切分成单词列表。
- 第 10 行：`set(words)` 去重，再用 `len()` 统计数量。
- 第 13 行：在小写后的文本中用 `in` 判断 `"python"` 是否存在。
