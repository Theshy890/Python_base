## 参考答案与解析

### 一、选择题答案

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | **B** | `if/elif/else` 只会执行第一个条件成立的分支。`75 >= 60` 成立，所以输出“及格”，后面的 `else` 不会执行。 |
| 2 | **A** | `range(1, 10, 2)` 从 1 开始，步长为 2，终点 10 不包含，所以生成 `1, 3, 5, 7, 9`。 |
| 3 | **B** | `==` 比较“值是否相等”，两个列表内容一样，所以为 `True`；`is` 比较“是不是同一个对象”，两个列表内存地址不同，所以为 `False`。 |
| 4 | **B** | `x and y > 0` 等价于 `x and (y > 0)`。`x = 0` 为假，所以整个条件为假，执行 `else` 分支，输出“不通过”。 |
| 5 | **D** | `break` 是彻底结束整个循环；`continue` 是跳过本次循环的剩余代码，继续下一轮。 |

### 三、代码实践题标准答案

#### 第 9 题标准答案

```python
prices = [25, 60, 15, 8, 42]
total = 0

for price in prices:
    total = total + price

if total >= 100:
    final = total * 0.8
elif total >= 50:
    final = total * 0.9
else:
    final = total

saved = total - final

print("原价：" + str(total))
print("实付：" + str(final))
print("节省：" + str(saved))
```

**逐行解释**：

```text
第1行：定义价格列表 prices。
第2行：初始化总价 total 为 0。
第4-5行：用 for 循环遍历每个价格，累加到 total 中。
第7-12行：用 if/elif/else 判断折扣规则，计算实付价格 final。
第14行：计算节省了多少钱。
第16-18行：输出结果，用 str() 把数字转成字符串后拼接。
```

#### 第 10 题标准答案

```python
words = ["Python", "", "AI", "  ", "应用", "开发", ""]
count = 0

for index, word in enumerate(words, 1):
    cleaned = word.strip()
    if not cleaned:
        continue
    count = count + 1
    print(str(index) + ": " + cleaned)

print("非空词数量：" + str(count))
```

**逐行解释**：

```text
第1行：定义词列表 words，其中包含空字符串和只含空格的字符串。
第2行：初始化非空词计数器 count 为 0。
第4行：用 enumerate(words, 1) 同时获取序号 index 和值 word，序号从 1 开始。
第5行：用 strip() 去掉首尾空格，得到 cleaned。
第6-7行：如果 cleaned 为空，continue 跳过本次循环，不统计也不打印。
第8行：有效词数量加 1。
第9行：输出序号和内容，用 str() 把序号转成字符串后拼接。
第11行：循环结束后，输出非空词总数量。
```

#### 第 11 题标准答案

```python
for i in range(1, 6):
    for j in range(1, i + 1):
        print(str(j), end=" ")
    print()
```

**逐行解释**：

```text
第1行：外层循环控制行数，i 从 1 取到 5。
第2行：内层循环控制每行输出几个数字，j 从 1 取到 i。
第3行：输出当前数字，end=" " 表示不换行，用空格连接。
第4行：内层循环结束后，print() 输出一个换行，开始下一行。
```

## 错题知识点速查表

| 题号 | 涉及知识点 | 错因提醒 |
|------|-----------|---------|
| 第 1 题 | `if/elif/else` 只走一条路 | 多个条件同时满足时，也只执行第一个成立的分支 |
| 第 2 题 | `range(起点, 终点, 步长)` | 终点不包含；步长为 2 时跳过偶数 |
| 第 3 题 | `==` 与 `is` 的区别 | `==` 比内容，`is` 比内存地址；列表即使内容相同也不是同一个对象 |
| 第 4 题 | `and / or` 优先级 | `and` 优先级低于比较运算，不确定时请加括号 |
| 第 5 题 | `break / continue` | `break` 结束整个循环，`continue` 只跳过本轮 |
| 第 6 题 | `print(end=...)` | `end=" "` 可以控制 print 结尾不换行 |
| 第 7 题 | `enumerate(列表, 起始序号)` | 默认从 0 开始，从 1 开始需要传第二个参数 |
| 第 8 题 | `continue / break` 用法 | `continue` 跳过本次，`break` 结束循环 |
| 第 9 题 | `if/elif/else` + `for` 累加 | 注意缩进和分支只走一条 |
| 第 10 题 | `continue` + `enumerate()` | 用 `strip()` 清理空格后再判断空值 |
| 第 11 题 | 循环嵌套 | 外层走一步，内层跑一圈；注意 print() 的位置决定换行时机 |
